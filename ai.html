Agent Skill

把 G6Lite Skill 交给 Agent

支持 Skill 的 Agent 会读取 $antv-g6lite-graph。它先确认数据规模、布局、交互和运行环境，再按当前 @antv/g6-lite 包根 API 写出可以继续验证的实现。

阅读 Skill 说明
bash
# 为 Agent 安装 Skill
$ npx skills add antvis/G6Lite --skill antv-g6lite-graph

# 然后在新的 Agent 会话里：
"使用 $antv-g6lite-graph 做一张力导向依赖图。
节点和边从当前项目里已有的数据文件读取，按 id、source、target 映射，不要让我粘贴数据。
加上悬停高亮和节点拖拽，容器给出明确尺寸，卸载时销毁 Graph。"

在 AI 里这样用

  1. 01安装 Skill

    把 antv-g6lite-graph 安装到支持 Skill 的 Agent，或把仓库目录 skills/antv-g6lite-graph 交给它。

  2. 02点名调用

    示例已经写明数据来源：让 Agent 读取当前项目里的节点和边，不用自己粘贴数据。

  3. 03按边界验收

    只使用包根 API。先渲染最小 Graph，在有尺寸的浏览器里检查，卸载时销毁实例。

Agent 写出的代码还需要类型检查、浏览器验证和业务数据验收。
