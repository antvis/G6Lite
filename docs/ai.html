在本地使用 Skill

将 GitHub 中的 skills/antv-g6lite-graph 目录作为 Skill 源交给支持 Skill 的 Agent，然后在任务中显式调用：

也可以直接让 Agent 从 GitHub 安装：

Skill 会重点约束：

  • 只从 @antv/g6-lite 包根导入，不依赖 src/ 或 dist/ 深层路径。
  • 使用 ESM 和真实浏览器的 DOM、Canvas、WebGL 生命周期。
  • 只生成 G6Lite 已支持的节点、边、布局、Behavior、Combo 和扩展能力。
  • 区分 G6Lite 与 G6 v5，不机械复制插件、事件或元素配置。
  • 对大图优先检查布局、标签密度、增量更新、DPR、GPU 和真实设备。

适合交给 Agent 的任务

任务推荐提示词重点
创建关系图数据字段、节点/边数量、布局、容器尺寸
增加交互选择、拖拽、Tooltip、高亮、框选或套索
迁移 G6 v5先列能力差异和不支持项，再修改代码
排查空白画布容器尺寸、数据端点、WebGL、生命周期和版本
优化大图首屏、布局、标签、状态 patch、内存和真实设备
创建扩展扩展类别、生命周期、公开 ExtensionContext 和清理

推荐工作流

  1. 澄清输入确认数据、规模、坐标、布局、交互和运行环境。
  2. 最小渲染先完成可见、可销毁、只使用包根 API 的最小图。
  3. 逐层增强依次加入样式、布局、Behavior、状态、Combo 与扩展。
  4. 真实验证在目标浏览器、DPR、GPU 和容器尺寸下检查结果。

AI 生成的代码仍需要类型检查、浏览器验证和业务数据验收。不要把 Agent 输出直接视为生产结果。
