Graph 需要真实的 DOM、Canvas 和 WebGL，不能在没有画布的环境里创建实例。

调用顺序

new Graph() 只保存配置并准备画布。布局、绘制和后续数据修改都要等 await graph.render() 完成。在此之前调用 setData()、addNode()、setItemState()、layout() 会抛出 Graph must be rendered before calling data operations。

查询方法在首次渲染前返回空结果：getNodes() 为 []，getNodeData() 为 undefined。graph.on() 可以在 render() 之前注册。
