从 G6 v5 迁移

G6Lite 需要现代 ESM 浏览器、真实 DOM/Canvas 和 WebGL 1.0。当前仍处于 0.1.x beta，Combo 的折叠、嵌套和运行时归组属于实验性能力。选型时先对照能力边界；从 G6 v5 迁移时再逐项核对配置、事件和运行时 API。
