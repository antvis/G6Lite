空白画布

检查容器是否已挂载且非零宽高、初始化是否报错、节点 ID 和端点是否有效。先只保留两个节点与一条边，移除可选样式和扩展。

尺寸正常仍报 WebGL 错误时，核对 GPU、宿主环境与 CSP；不要反复创建 Graph。 环境要求 · 数据身份规则

图特别小或位置不对

先检查异常坐标、离群节点和容器尺寸，再决定 fitView 的 padding / maxZoom。首次 render、容器 resize、setData 和 layout 的适配语义不同，不要在每次用户缩放后强制适配。 适配后图仍然很小

标签消失或重叠

确认 node / edge.style.label 产生了文本，再检查缩放阈值、碰撞、颜色与容器裁剪。先关闭策略做对照，再逐项恢复。 标签指南 · 策略字段

点击、拖拽或边事件无响应

确认 behaviors 列表、所需 Behavior 与组合键；[] 会关闭默认。再检查覆盖画布的 DOM、边热区和事件类型。只监听派生事件不会自动启用行为。 交互组合 · 事件参考

Worker 没运行或回退

在 Network/Performance 检查模块 Worker 请求、执行线程、克隆错误和服务器响应。普通函数与循环引用配置不能直接克隆；worker: true 不是成功证据。 Worker 部署与取消

卸载后残留或重复响应

逐个匹配创建与 destroy、on 与 off、业务请求与取消。StrictMode 的额外挂载应正常清理，不通过跳过 setup 隐藏问题。 React · Vue · 扩展清理

性能问题

力导向布局首屏慢怎么办？

分开测量布局和 render；已有坐标时省略 layout，支持时评估 Worker 与迭代参数。步骤见性能优化。

高亮或选中卡顿怎么办？

复用 Graph，通过状态 API 更新，不为一次高亮重建或替换整图。见状态指南。

安装与运行环境

浏览器和 WebGL 要求是什么？

需要真实 DOM、Canvas 2D 和可用的 WebGL1 或 WebGL2。具体模块、Worker 和 CSP 约束见运行环境。

能在 Node.js 或 SSR 阶段直接运行吗？

Graph 不能在普通 Node.js / SSR 阶段出图。在客户端挂载后创建并在卸载时销毁，见框架接入。

TypeScript 类型从哪里导入？

值和类型均从 @antv/g6-lite 包根导入，以已安装版本的类型声明为准。构造参数及数据类型见配置项。

安装后某个字段不存在怎么办？

先检查实际版本和包根类型，不复制开发分支字段。安装与 UMD 的已知发布物差异见快速上手。
