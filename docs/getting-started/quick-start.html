安装与第一个图

安装 G6-GL，准备容器，并渲染第一个可交互图

G6-GL 的最小使用链路是：安装依赖、准备一个有宽高的容器、创建 Graph、传入数据与配置、调用 render()。

画布默认支持滚轮缩放和拖拽平移；只有节点拖拽、选择、高亮等元素级交互需要显式配置。

代码做了什么

  1. data.nodes 定义节点，id 是唯一标识，业务字段放在 data 中。
  2. data.edges 定义边，source 和 target 指向节点 id。
  3. node 和 edge 配置元素类型、样式、标签与状态样式。
  4. layout 决定节点坐标；不传布局时会使用节点上的 x / y。
  5. behaviors 在默认缩放和画布拖拽之外，继续启用节点拖拽、选择和悬停高亮。
  6. await graph.render() 执行布局、初始化渲染管线并绘制首帧。
