安装与第一个图

安装 G6Lite，准备容器，并渲染第一个可交互图

在 GitHub 查看源码

G6Lite 的最小使用链路是：安装依赖、准备一个有宽高的容器、创建 Graph、传入数据与配置、调用 render()。

画布默认支持平滑滚轮缩放和拖拽平移；只有节点拖拽、选择、高亮等元素级交互需要显式配置。缩放灵敏度和范围可通过 zoom-canvas 调整。

准备容器

container 可以是 DOM id、选择器或 HTMLElement。容器必须有明确宽高，否则画布会退回默认尺寸。

渲染基础图

代码做了什么

  1. data.nodes 定义节点，id 是唯一标识，业务字段放在 data 中。
  2. data.edges 定义边，source 和 target 指向节点 id。
  3. layout 决定节点坐标；不传布局时会使用节点上的 x / y。
  4. behaviors 启用画布缩放、画布拖拽、节点拖拽和悬停高亮。
  5. await graph.render() 执行布局、初始化渲染管线并绘制首帧。

常用配置

选项说明继续阅读
container挂载画布的 DOM 容器本页
data图数据，包含 nodes、edges、可选 combos数据
node节点类型、样式、状态样式、标签节点
edge边类型、样式、箭头、标签边
combo节点分组容器样式Combo
layout布局算法与参数布局
behaviors交互行为列表交互
themelight、dark 或 token 覆盖主题
