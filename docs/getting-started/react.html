在框架中使用

在 React 和 Vue 3 中挂载图、更新数据并管理实例生命周期

适配容器尺寸

容器必须有明确宽高，只有 width: 100% 不够。上面的示例使用固定高度 480；在弹性布局中，也可以用 CSS 设置高度或 min-height。

G6Lite 通过 ResizeObserver 同步 canvas 尺寸，默认保留用户当前的缩放和平移。示例中的 autoFit 会在尺寸变化时重新适配图，并限制 padding 和最大缩放。配置详情见Graph 生命周期。

Vue 示例使用内联样式设置 480px 高度。使用百分比高度时，父容器也需要确定的高度。图组件放在隐藏页签或弹窗中时，建议在容器显示且尺寸确定后再创建实例。

卸载与清理

React

在 effect 的 cleanup 中调用 graph.destroy()，释放 canvas、事件监听、观察器和布局任务，同时清空保存的引用。

React Strict Mode 在开发环境会额外执行一次 effect 的创建与清理。保留 cleanup，让每次创建都对应一次销毁，避免残留画布或事件监听。参见 React 的 effect 清理说明。

Vue

在 onBeforeUnmount 中调用 graph.destroy()，释放 canvas、事件监听、观察器和布局任务，并清空实例引用。Vue 会在组件卸载时停止同步创建的 watcher；示例中的清理回调也会阻止尚未开始的数据更新。参见 Vue 生命周期钩子。
