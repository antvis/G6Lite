校验数据

  • 节点 id 在图内唯一，后续更新时保持稳定。
  • 边的 source 和 target 必须对应已有节点。
  • 使用 Combo 时，节点的 comboId 应对应已声明的分组。
  • 未配置布局时，应提供节点的 x / y，避免所有节点落在缺省坐标。
  • 修改图数据应通过公开方法完成，不要直接改写查询返回的 Model。
