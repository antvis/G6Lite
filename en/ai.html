Agent Skill

Give your agent the G6Lite Skill.

An agent that supports Skills reads $antv-g6lite-graph. It checks data scale, layout, interactions, and the runtime, then writes an implementation through the current @antv/g6-lite package-root API.

Read the Skill guide
bash
# install the skill for your agent
$ npx skills add antvis/G6Lite --skill antv-g6lite-graph

# then, in a new agent session:
"Use $antv-g6lite-graph to build a force-directed dependency graph.
Read nodes and edges from the data files already in this project, and map id, source, and target. Do not ask me to paste the dataset.
Add hover highlighting and node dragging, give the container an explicit size, and destroy the graph on unmount."

Use it in an AI session

  1. 01Install the Skill

    Install antv-g6lite-graph into an agent that supports Skills, or point it at skills/antv-g6lite-graph in this repository.

  2. 02Invoke it by name

    The example already names the data source: the agent reads nodes and edges from this project, so you do not paste the dataset.

  3. 03Check the boundary

    Stay on package-root APIs. Render a minimal Graph, validate it in a sized browser, and destroy the instance on unmount.

Code from an agent still needs type checking, browser validation, and a review against product data.
