Picking and gestures

Hit testing checks nodes, edges, Combos, then the canvas. When the pointer changes targets, the old target receives pointerleave, followed by pointerover, pointerenter, and pointermove on the new target. Over a Combo background, canvas:pointermove also fires and the wheel emits canvas:wheel. Dragging can suppress the following click.

Enable click-select, brush-select, or lasso-select to receive the corresponding events. They fire after selection state is written.

Hit nodes during lasso selection.lasso:select——

Callback fields

FieldMeaning
nodeId / edgeIdThe ID of the element whose selection changed. Edge events also provide edgeIndex, source, and target.
selectedThe updated selection state after a toggle.

nodeIdsNode IDs reported by brush and lasso events. brush:end returns all currently selected nodes when the gesture ends.

With brush-select enabled, listen for brush:end to read the selected nodes when the gesture ends.

Lasso events report the nodes hit by the current gesture. Use findNodesByState('selected') and findEdgesByState('selected') for the full graph selection. Selection and drag guide

Drag events

drag-node handles node and Combo drags. drag-edge handles endpoint drags.

ActionNodeEdgeCombo
Start dragging. Nodes and Combos must move more than 3 CSS pixels. Edges start on primary-button press.node:dragstartedge:dragstartcombo:dragstart
Drag in progress. Node and Combo events fire after the node or Combo member positions are updated.node:dragedge:dragcombo:drag
Release the mouse button to end the drag.node:dragendedge:dragendcombo:dragend

Callback fields

FieldMeaning
nodeId / nodeIdsThe first dragged node ID and the full list of dragged node IDs in node drag events.
comboIdThe dragged Combo’s ID in Combo drag events.
dx / dyCumulative displacement from the start, in graph coordinates, in node:drag and combo:drag.
edgeId / edgeIndexThe edge ID and index in edge drag events. edgeId is optional.
source / targetEndpoint node IDs. On a valid drop, edge:dragend returns proposed endpoints for the application to validate and apply.
dragEndThe endpoint being dragged in edge:dragstart and edge:drag (source or target). The closer endpoint is chosen, with target used on a tie.

reconnected / newEndpointWhether the drop hit a valid target and, when present, its node ID in edge:dragend.
eventThe original MouseEvent. Node and Combo dragend events provide only the drag result.

At the end of the drag, use nodeIds to look up the positions of all dragged nodes.

EventEmitter

Use EventEmitter to send custom events between UI components. Pass a rendered graph, the toolbar’s Reset view button, and a status element to bindResetView(). Clicking the button restores the initial view and updates the status. Call the returned cleanup function when the page unmounts.
