Use with React and Vue

Handle container resizing

Give the container explicit dimensions. Setting only width: 100% is insufficient. The example uses a height of 480; flexible layouts can set a height or min-height through CSS.

G6Lite uses ResizeObserver to synchronize canvas dimensions and preserves the current camera by default. The example's autoFit option fits the graph after a resize while controlling padding and maximum zoom. See Graph lifecycle.

The Vue example uses an inline height of 480px. Percentage heights require a parent with a defined height. For hidden tabs or dialogs, create the instance once the container is visible and has a real size.

Clean up on unmount

React

Call graph.destroy() in the effect cleanup to release the canvas, event listeners, observers, and layout tasks, then clear the stored refs.

React Strict Mode runs an extra effect setup and cleanup cycle during development. Pair each creation with cleanup to avoid leftover canvases and listeners. See React's effect cleanup guidance.

Vue

Call graph.destroy() in onBeforeUnmount to release the canvas, event listeners, observers, and layout tasks, then clear the instance reference. Vue stops watchers created synchronously during setup when the component unmounts; the cleanup callback also prevents pending updates from starting. See Vue lifecycle hooks.
