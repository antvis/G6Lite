Rendering, layout, and data updates

Know when to update the graph, read node positions, or respond to data replacement.

View source on GitHub

When can I continue?

TaskWhat to do
Update the graph after its first renderWait for await graph.render(), then change data or states.
Read positions after running a layoutWait for await graph.layout(), then call getNodePosition().
Update the application after each data replacementListen for datachange to receive the new node and edge counts.

To receive a notification for the first render, register graph.once('afterrender', handler) before calling render(). The layout:end and afterlayout events fire before positions are written back. Await graph.layout() before reading final positions.
