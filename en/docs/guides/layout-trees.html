Tree layouts

Show parent-child relationships with mind maps, indented trees, and fishbone diagrams

View source on GitHub

Choose a layout

Express parent-child relationships as edges with the parent as source and the child as target. Use one connected tree with a single root and no cycles.

GoalLayout and common options
Mind map branchesmindmap, with levelGap between levels and nodeGap between neighbors on the same side
Directory listingindented, with indent for indentation and rowHeight for row spacing
Root, categories, and itemsfishbone, with categoryGap between categories along the spine

Configuration and example

Use Tree layout to compare the three arrangements. The example also changes the edge routing. Indented trees use elbow connectors, while the fishbone layout uses angled branches.

Register each tree layout before using it. Optional layouts

See the tree layout reference for defaults and other options.
