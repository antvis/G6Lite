# 官网样式美化方案变更记录

> 日期：2026-06-24
> 类型：方案文档

## 变更内容

- 新增 `openspec/specs/website-style-refresh/spec.md`，记录官网样式美化的技术方案。
- 明确本次美化范围为 `website/` 官网首页、全局视觉 token、文档导航和通用组件样式。
- 给出 Hero、视觉 token、卡片控件、图标系统、首页区块节奏、文件变更计划和验证方式。
- 根据用户补充的参考站 `https://infographic.antv.vision/`，进一步明确风格方向：白底留白、玫红强调、胶囊导航、轻卡片、大标题、真实缩略图展示。

## 变更原因

项目规范要求功能开发或优化任务先产出技术方案文档，经确认后再开始编码。本次用户提出“美化官网样式”，属于官网视觉优化任务，因此先补充方案。

## 影响

- 当前仅新增方案和变更记录，不修改官网运行时代码。
- 后续实现将以该方案为依据，重点调整首页视觉表现和样式一致性。
