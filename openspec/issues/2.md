# 基础视觉完善：边、节点、分组

## 背景

G6Lite 当前完成了基础的图渲染能力（节点/边绘制、布局、交互），但视觉细节与设计稿仍有较大差距。本 Issue 旨在根据设计稿系统性地完善边、节点、分组三类元素的视觉表现，使其达到可交付状态。

---

### 1.1 已实现（需打磨）

| 能力 | 状态 | 待完善 |
|------|------|--------|
| 边状态系统（6 态） | ✅ 基本可用 | Active/Selected 缺少 halo 光晕效果 |
| 箭头（飞镖形） | ✅ 已实现 | 弧形边箭头方向已沿切线 |
| 虚线 | ✅ 已实现 | — |

| 弧形边 | ✅ 已实现 | — |
| 自环边（嵌套） | ✅ 基本可用 | — |

## 三、分组（Combo）视觉

### 3.1 目标

支持节点分组渲染，分组以包围框的形式展示，子节点包含在分组内。参考业务中 GeaFlow 实现计划图的 combo-combined 布局用法。

### 3.2 需实现

| 能力 | 优先级 | 说明 |
|------|--------|------|
| 分组渲染（圆形/矩形） | P1 | 根据子节点范围计算包围框，支持 padding |
| 分组样式 | P1 | fill（半透明背景）、stroke（边框）、label（标题） |
| 分组嵌套 | P2 | 分组可包含子分组，层级渲染 |
| 分组折叠/展开 | P3 | 交互式折叠分组为单节点 |
| 分组拖拽 | P3 | 拖拽分组时子节点跟随 |

---

## 验收标准

1. 每个功能完成后新增对应 playground demo
2. 性能不退化（5K 节点 + 15K 边场景基准）
3. 视觉对照设计稿截图验证
4. 变更记录更新至 `openspec/changes/`
5. 技术方案先产出至 `openspec/specs/<feature>/spec.md`

## 实施顺序建议

1. **P1 基础**：节点状态 + 节点边框 + 圆角矩形 + Halo 光晕 + 分组基础渲染
2. **P2 增强**：平行边 + 节点 icon/badge + 分组嵌套
3. **P3 文本**：边文本 + 边标签 + 分组折叠/拖拽
