# 思维导图布局 — 需求文档

## 1. 概述

为 G6Lite 新增思维导图（Mind Map）布局能力，支持从中心根节点向两侧或单侧展开子树的可视化场景。典型应用：知识结构梳理、项目分解、因果分析等。

---

## 2. 设计稿分析

### 设计稿 A — Modeling Methods（双向展开，多层级）

- 根节点 "Modeling Methods" 居中
- 左侧展开 "Regression" 分支（5 个叶子节点）
- 右侧展开 "Classification"（6 个叶子）、"Consensus" 下含 "Model diversity"（6 个叶子）和 "Methods"/"Content" 等子树
- 每个一级分支独立配色：蓝色系、橙色系、绿色系、粉色系
- 节点为圆角矩形，根节点无边框加粗显示
- 父子之间用 **S 型三次贝塞尔曲线** 连接
- 同一父节点的多条边从父节点侧面共享出发点，扇形展开到各子节点

### 设计稿 B — 项目计划（单向展开，两层）

- 根节点 "项目计划" 在最左侧
- 仅向右展开，两层结构
- 一级节点：研究阶段、设计阶段、开发阶段、测试阶段
- 每个一级分支独立配色（蓝、橙、绿、紫）
- 边使用 **S 型曲线**，同一父节点的边共享出发点后分叉
- 节点圆角矩形，带 2px 左右的细边框

### 设计稿 C — 台风形成因素（双向展开，暖色主题）

- 根节点 "台风形成的因素" 居中，深色背景
- 左侧 "地理环境"（4 个叶子），右侧 "气象条件"（4 个叶子）
- 统一暖色调：根节点深绿/灰，分支和叶子为砖红色系
- 同样使用 S 型曲线连接
- 整体背景为米色/暖灰

---

## 3. 功能需求

### F-01: 思维导图布局算法

| 项目 | 描述 |
|------|------|
| 根节点定位 | 根节点置于画布中心 (0, 0) |
| 双向展开 | 一级子节点自动分配到左右两侧（交替或按数量均分） |
| 单向展开 | 支持仅向右展开（类似设计稿 B） |
| 子树独立计算 | 每侧子树独立计算纵向坐标，避免子树间重叠 |
| 节点自适应大小 | 节点宽度可根据文本长度自适应 |

**布局配置项：**

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `direction` | `'H'` \| `'LR'` \| `'RL'` | `'H'` | H=双向，LR=仅右展开，RL=仅左展开 |
| `levelGap` | number | 120 | 层间水平距离 |
| `nodeGap` | number | 30 | 同层节点垂直间距 |
| `branchColors` | string[] | 内置色板 | 按一级子树索引分配的分支颜色 |
| `getSide` | (node) => 'left' \| 'right' | 自动均分 | 自定义一级子节点分配到左/右侧的逻辑 |

### F-02: S 型贝塞尔曲线边

| 项目 | 描述 |
|------|------|
| 曲线类型 | 水平方向三次贝塞尔曲线（Cubic Bezier） |
| 曲线形态 | 从父节点侧面水平延伸，到中间转向，S 型平滑到达子节点侧面 |
| 共享出发点 | 同一父节点的所有子边共享父节点侧面中心为起点 |
| 扇形分叉 | 多条子边从共享起点自然分叉到各子节点 |

**边配置项：**

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `style.lineWidth` | number | 2 | 边线宽度 |
| `style.stroke` | string \| function | 分支色 | 边颜色，支持函数按节点动态返回 |
| `style.curveOffset` | number | `levelGap * 0.4` | 控制点水平偏移量，影响 S 曲线弯曲程度 |
| `style.endArrow` | boolean | false | 是否显示箭头 |

### F-03: 分支配色

| 项目 | 描述 |
|------|------|
| 按分支染色 | 每个一级子树（含其所有后代）使用同一颜色 |
| 节点+边一致 | 同一分支的节点边框色与边颜色一致 |
| 内置色板 | 提供默认色板，支持用户自定义 |
| 根节点特殊样式 | 根节点使用独立配色，字体更大或加粗 |

**配色配置项：**

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `layout.branchColors` | string[] | 内置色板 | 按一级子树分配的分支颜色 |
| `node.style.fill` | string \| function | 白色 | 节点填充色，支持函数 |
| `node.style.stroke` | string \| function | 分支色 | 节点边框色，支持函数 |
| `node.style.strokeWidth` | number \| function | 2 | 节点边框宽度 |

### F-04: 节点样式

| 项目 | 描述 |
|------|------|
| 节点形状 | 圆角矩形 |
| 根节点 | 更大尺寸，独立填充色，无边框或粗边框 |
| 子节点 | 较小尺寸，白色或浅色填充，带分支色边框 |
| 文字 | 节点内居中显示，根节点字号稍大 |

**节点配置项：**

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `node.style.width` | number \| function | 120 | 节点宽度，支持函数按节点动态返回 |
| `node.style.height` | number \| function | 36 | 节点高度 |
| `node.style.borderRadius` | number \| function | 6 | 圆角半径 |
| `node.style.fill` | string \| function | '#fff' | 填充色 |
| `node.style.stroke` | string \| function | 分支色 | 边框色 |
| `node.style.opacity` | number \| function | 1 | 透明度 |

### F-05: 主题适配

| 项目 | 描述 |
|------|------|
| 亮色主题 | 白色背景 + 彩色分支（设计稿 A、B） |
| 暖色主题 | 米色背景 + 暖色调分支（设计稿 C） |
| 暗色主题 | 深色背景适配 |

---

## 4. 交互需求

| 项目 | 描述 |
|------|------|
| 缩放 | 支持滚轮缩放 |
| 拖拽画布 | 支持拖拽平移 |
| 自适应视图 | 首次渲染后 fitView 居中展示 |

---

## 5. Demo 需求

提供一个 `playground/demos/mindmap.ts` 示例：

1. 默认展示双向思维导图（类似设计稿 A 或 C 的结构）
2. 提供按钮切换：双向展开 / 仅右展开
3. 提供主题切换：亮色 / 暖色
4. 数据量：15-30 个节点，3-4 层深度

---

## 6. 不在本期范围

- 节点的展开/折叠交互
- 拖拽节点调整位置
- 垂直方向的思维导图（上下展开）
- 节点图标/图片
- 导出图片功能
