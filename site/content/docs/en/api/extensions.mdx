title: Extensions
description: Canonical registration, drawing, runtime, and configuration contract entries

Choose a contract by capability; follow [Extension system](/en/docs/guides/extensions) for implementation. Drawing and runtime categories have different lifecycles.

## `register()`

See [registration and context](/en/docs/api/extensions/registration#register) for overloads, naming, replacement, compatibility, and types.

| Category | Activation | Public contract |
| --- | --- | --- |
| node | node.type | [NodeExtension](/en/docs/api/extensions/drawing#nodeextension) |
| edge | edge.type | [EdgeExtension](/en/docs/api/extensions/drawing#edgeextension) |
| label | node / edge.labelRenderer | [LabelRenderer](/en/docs/api/extensions/drawing#labelrenderer) |
| decoration | node.decorations[].renderer | [DecorationRenderer](/en/docs/api/extensions/drawing#decorationrenderer) |
| behavior | behaviors | [BehaviorExtension](/en/docs/api/extensions/runtime#behaviorextension) |
| layout | layout.type | [LayoutExtension](/en/docs/api/extensions/runtime#layoutextension) |
| transform | transforms | [TransformExtension](/en/docs/api/extensions/runtime#transformextension) |
| plugin | plugins | [PluginExtension](/en/docs/api/extensions/runtime#pluginextension) |

See [Transform / Plugin options](/en/docs/api/options/transforms-plugins) for shapes, ordering, and update boundaries.

## `extensionFactory()`

Marking a factory does not create an instance immediately or imply exactly one call per Graph. See the [factory contract](/en/docs/api/extensions/registration#extensionfactory) for input forms and instance scope.

## Extension context

[ExtensionContext](/en/docs/api/extensions/registration#extensioncontext) defines snapshots, writes, state replacement, coordinates, scheduling, and destruction. See [runtime contracts](/en/docs/api/extensions/runtime) for operation inputs and timing.

## `runLayout()`

See [runLayout](/en/docs/api/graph/layout#runlayout) for standalone calculation, viewport, cancellation, and live results. Use [layout methods](/en/docs/api/graph/layout) for an existing Graph. Standalone calculation skips Layout.init; follow [Custom layouts](/en/docs/guides/custom-layout) for implementation.
