Graph operates one graph. Choose a task and click a member for arguments, returns, units, prerequisites, and boundaries. Creation and subscription can precede render; ordinary data and state writes wait for a valid render.

Start with [lifecycle](/en/docs/concepts/graph-lifecycle), or look up [GraphOptions](/en/docs/api/options). Find compatibility members and internal boundaries in [API stability](/en/docs/compatibility/api-stability), outside the recommended index.
