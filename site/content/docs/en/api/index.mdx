All supported imports come from `@antv/g6-gl`.

```ts
import { Graph, extensionFactory, register, runLayout } from '@antv/g6-gl';
import type { EdgeConfig, GraphData, GraphOptions, NodeConfig } from '@antv/g6-gl';
```

## Main runtime APIs

- `Graph`: create, render, update, query, relayout, control the viewport, and destroy a graph.
- `runLayout()`: run a supported layout independently.
- `register()`: register node, edge, label, behavior, layout, transform, decoration, or plugin extensions.
- `extensionFactory()`: provide isolated stateful extension instances.

## Type groups

Package-root types cover graph options and data, nodes, edges, combos, labels, states, themes, layouts, viewport operations, behaviors, transforms, plugins, and extension context.
