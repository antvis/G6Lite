description: Important G6-GL beta changes and migration boundaries
---

G6-GL is currently in the `0.1.0-beta` series. Recent work has concentrated on package-root API boundaries, functional extensions, isolated extension lifecycle, read-only query models, layout cancellation, combo consistency, interaction dispatch, package size governance, examples, and reproducible benchmarks.

Deprecated beta compatibility APIs remain documented in [API stability](/en/docs/compatibility/api-stability). Projects migrating from G6 v5 should follow the [migration guide](/en/docs/compatibility/g6-v5-migration).

Before upgrading, run type checking, tests, a package build, size-limit, release examples, and target-device validation.
