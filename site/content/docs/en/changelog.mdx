The checked GitHub Releases/tags return beta.24; npm beta.27 does not imply a matching GitHub Release. At verification, public npm latest points to beta.1 and beta to beta.27. Tags can change, so tutorials pin a version. Raw evidence is in site/maintenance/b90-release-evidence.json.
