Scope: G6 5.1.1 [official integration](https://g6.antv.antgroup.com/en/manual/getting-started/quick-start) and current G6Lite source. G6Lite is not a compatible G6 build. Check [published/source differences](/en/docs/compatibility/api-stability) first.

## Decide whether to migrate

Validate the most complex nodes, interactions, labels, and groups first. Keep G6 when arbitrary DOM/React nodes, multiple renderers, server rendering, full animation, algorithms, or established plugins are essential. Use the [capability comparison](/en/docs/compatibility/library-comparison), not package size alone.

## Installation and imports

```bash
npm install @antv/g6-lite@0.1.0-beta.27
```

Import values and types from @antv/g6-lite only; do not migrate to deep src/dist paths.

## Minimal configuration comparison

G6 v5 commonly uses a container ID, labelText, and drag-element; see the [official example](https://g6.antv.antgroup.com/en/manual/getting-started/quick-start). This standalone G6Lite starting point needs a mounted, non-zero-size container:

```ts
import { Graph } from '@antv/g6-lite';

export async function mountGraph(container: HTMLElement) {
  const graph = new Graph({
    container,
    data: {
      nodes: [{ id: 'a' }, { id: 'b' }],
      edges: [{ id: 'a-b', source: 'a', target: 'b' }],
    },
    node: { style: { label: (node) => node.id } },
    layout: { type: 'circular', radius: 100 },
    behaviors: ['zoom-canvas', 'drag-canvas', 'drag-node', 'click-select'],
  });
  try {
    await graph.render();
    graph.fitView({ padding: 32, maxZoom: 1 });
    return () => graph.destroy();
  } catch (error) {
    graph.destroy();
    throw error;
  }
}
```

Call the returned disposer for cleanup. For React/Vue asynchronous unmounting, use the [framework pattern](/en/docs/getting-started/react) instead of leaving a mounting task unmanaged.

## GraphOptions mapping

| G6 v5 | G6Lite |
| --- | --- |
| container ID | CSS selector #container, or HTMLElement |
| node.style.labelText | node.style.label |
| width / height | Container CSS; runtime setSize |
| palette / renderer / animation | Not drop-in equivalents; map styles or keep G6 |
| setOptions | updateOptions only node / edge / label / theme; set layout separately |
| plugins / transforms / behaviors | Recheck registration, names, options, and lifecycle |

Complete fields: [GraphOptions](/en/docs/api/options)。

## Data field mapping

Provide nodes/edges arrays, unique node IDs, and valid endpoints. Keep stable edge IDs. Use node x/y, comboId, and business data fields. Do not copy G6 internal models or assume per-node style compatibility.

Runtime node additions require positions; full replacement and incremental writes differ. See [input data](/en/docs/api/options/data) · [data updates](/en/docs/guides/data)。

## Node, Edge and Combo configuration

Built-in circle/rect and common edges reuse WebGL primitives; they do not replace arbitrary scene-graph shapes. State styles live in node.stateStyles, edge.stateStyles, and combo.style.stateStyles. Nested/collapsed/runtime-grouped Combo remains experimental.

[Nodes](/en/docs/api/options/node) · [Edges](/en/docs/api/options/edge) · [Combo](/en/docs/api/options/combo)

## Behavior mapping

| G6 v5 | G6Lite |
| --- | --- |
| drag-element | drag-node |
| hover-activate | hover-highlight or state APIs |
| collapse-expand | collapseCombo / expandCombo / toggleCombo |
| create-edge | Application creation + addEdge; drag-edge only reconnects existing edges |
| focus-element | focusItem |
| zoom-canvas / click-select | Names may match; recheck options, payloads, and modifiers |

Omitted behaviors enable default zoom/pan; [] disables them. See [Behavior](/en/docs/api/options/behaviors)。

## Layout migration

Matching names do not guarantee matching options. Fix data and node sizes when mapping center, rankdir, iteration, and distance options. At runtime call setLayout then await layout. See [layout contracts](/en/docs/api/graph/layout) for cancellation and Worker boundaries.

## Event migration

Use string names and GraphEventMap instead of G6 event enums. Element native events use nativeEvent; selection/drag derived payloads have their own contracts. Do not replace every event field globally. Pair listeners with off.

[Event contracts](/en/docs/api/graph/events) · [Application event guide](/en/docs/guides/events)

## Graph API mapping

| G6 v5 | G6Lite lookup |
| --- | --- |
| getNodeData(id?) / getEdgeData(id?) | Separate single/list calls: getNodeData / getNodes, getEdgeData / getEdges |
| addNodeData / removeNodeData | addNode(s) / removeNode(s) |
| setElementState / getElementState | setElementStates / getItemStates |
| hideElement / showElement | hideItem / showItem |
| focusElement / resize | focusItem / setSize |
| draw / render | render and refresh differ; consult lifecycle |

Use the [method index](/en/docs/api/graph) for full arguments, returns, and missing-ID behavior. New code should avoid toData, isDestroyed, and internal getCanvas/updateData.

## Extension, Transform and Plugin

G6 base classes do not migrate unchanged. Select the category and follow [tutorials](/en/docs/guides/extensions) and [contracts](/en/docs/api/extensions). The controlled context is not a full Graph. Hosts can explicitly inject plugin subscriptions, with cleanup in destroy.

## Unsupported capabilities and alternatives

Run algorithms in a separate analysis pipeline and write results into data. Implement peripheral controls in application UI or Plugins. Keep G6 pages that cannot fit supported primitives, runtimes, or lifecycles; partial migration is not full compatibility.

## Migration acceptance checklist

1. Pin both versions and retain the original fallback.
2. Verify data, styles, labels, states, groups, and key gestures.
3. Cover updates, unsubscription, asynchronous unmounting, and repeated mounting.
4. Measure layout, rendering, interactions, and resources under equivalent visual/runtime conditions before switching.
