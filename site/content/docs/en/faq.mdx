## How should I choose between G6Lite and G6 v5?

Compare required graphics, runtime, and interactions, then validate business data. See the [capability comparison](/en/docs/compatibility/library-comparison).

## What if force layout makes startup slow?

Measure layout separately from render. Omit layout for supplied positions and assess Worker/iteration options where supported. See [performance tuning](/en/docs/metrics/performance-tuning).

## What if highlighting or selection stutters?

Reuse Graph and update states instead of rebuilding or replacing the graph for a highlight. See the [state guide](/en/docs/guides/states).

## What browsers and WebGL capabilities are required?

Real DOM, Canvas 2D, and a usable WebGL1 or WebGL2 context are required. See [runtime requirements](/en/docs/compatibility/browser) for modules, Worker, and CSP.

## Can Graph run directly in Node.js or during SSR?

Graph does not render in ordinary Node.js/SSR. Create it after client mounting and destroy on unmount; see [framework integration](/en/docs/getting-started/react).

## Where should TypeScript types be imported from?

Import values and types from @antv/g6-lite, using installed declarations. Development source and npm archives can differ; see [stability](/en/docs/compatibility/api-stability).

## Can I use Combo?

Grouping, nesting, and collapsing can be evaluated but remain experimental. Check [Combo boundaries](/en/docs/api/options/combo).

## Can examples run online?

Run the [example gallery](/en/docs/examples); each case includes code, data descriptions, and interaction expectations.

## What if the canvas is blank, tiny, or missing labels?

Follow [troubleshooting](/en/docs/compatibility/troubleshooting): check dimensions/data before restoring layout, labels, and behaviors individually.

## What if an installed package does not contain a field?

Identify the actual version and root types rather than copying development-only fields. See [installation](/en/docs/getting-started/quick-start) for known archive and UMD differences.
