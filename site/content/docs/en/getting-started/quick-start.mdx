## Package manager

This tutorial pins `0.1.0-beta.27`. The npm latest tag may point to an earlier version; check installed versions and types when upgrading. The introductory code is checked against published types. Development features such as autoFit differ from the archive; use only fields available in the installed package.

For projects using a bundler such as Vite or Webpack, install G6Lite with one of the following package managers:

<div className="quick-start-install">

```bash
# npm
npm install @antv/g6-lite@0.1.0-beta.27
```

```bash
# pnpm
pnpm add @antv/g6-lite@0.1.0-beta.27
```

```bash
# Yarn
yarn add @antv/g6-lite@0.1.0-beta.27
```

</div>

After installation, add a container with an explicit size:

```html
<div id="container" style="width: 100%; height: 360px"></div>
```

Then create a graph in your JavaScript or TypeScript entry after the container has mounted. Use `await` in an ES module or an `async` function.

```ts
import { Graph } from '@antv/g6-lite';

const data = {
  nodes: [
    { id: 'Alice', data: { color: '#5B8FF9', size: 40 } },
    { id: 'Bob', data: { color: '#5B8FF9', size: 28 } },
    { id: 'Carol', data: { color: '#5B8FF9', size: 28 } },
    { id: 'David', data: { color: '#61DDAA', size: 40 } },
    { id: 'Eva', data: { color: '#61DDAA', size: 28 } },
    { id: 'Frank', data: { color: '#61DDAA', size: 28 } },
  ],
  edges: [
    { source: 'Alice', target: 'Bob' },
    { source: 'Alice', target: 'Carol' },
    { source: 'David', target: 'Eva' },
    { source: 'David', target: 'Frank' },
    { source: 'Alice', target: 'David' },
    { source: 'Bob', target: 'Eva' },
    { source: 'Carol', target: 'Frank' },
  ],
};

const graph = new Graph({
  container: '#container',
  data,
  node: {
    style: {
      size: (node) => Number(node.data?.size ?? 26),
      fill: (node) => String(node.data?.color ?? '#5B8FF9'),
      stroke: '#fff',
      strokeWidth: 2,
      label: (node) => node.id,
      labelPlacement: 'bottom',
      labelColor: '#334155',
    },
  },
  edge: { style: { stroke: '#CBD5E1', lineWidth: 1.5 } },
  layout: {
    type: 'd3-force',
    linkDistance: 100,
    nodeStrength: -400,
    collideRadius: 32,
  },
  behaviors: ['zoom-canvas', 'drag-canvas', 'drag-node', 'hover-highlight'],
});

try {
  await graph.render();
  graph.fitView({ padding: 48, maxZoom: 1.2 });
} catch (error) {
  graph.destroy();
  throw error;
}
```

The force-directed layout positions the nodes automatically. Node data controls their colors and sizes, and `behaviors` enables zoom, pan, node dragging, and hover highlighting. TypeScript declarations are included in the package.

## CDN

The checked npm `0.1.0-beta.27` archive does not include `dist/g6-lite.min.js`; that npm CDN file URL cannot be used. For script integration, build from source that provides UMD:

```bash
git clone https://github.com/antvis/G6Lite.git
cd G6Lite
git checkout 6fec8e82
npm install
npm run build
```

The output is `dist/g6-lite.min.js`; Node.js 20+ is required. UMD exposes the API through `window.G6Lite`.

Place the built file beside index.html below and serve the folder with a static server. Alternatively upload the script to your own CDN and replace src. The UMD build inlines runtime dependencies and layouts.

## Verify and clean up

Expect 6 labeled nodes and 7 edges. Try wheel zoom, dragging the background, dragging a node, and hover highlighting. For a blank graph, check non-zero container dimensions, WebGL, and console errors; see the [FAQ](/en/docs/faq).

Run the package example after the real DOM is mounted. Before unmounting a component or removing its container, call:

```ts
graph.destroy();
```

Removing DOM alone does not replace instance cleanup. The CDN single-page example uses pagehide; recreate the graph if the page returns from the browser's back/forward cache. Use the framework lifecycle below for application routes.

## Use in frontend frameworks

In React and Vue, obtain the DOM element through a ref, create the graph after client-side mount, and call `graph.destroy()` on unmount.
