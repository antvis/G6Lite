## Configuration

Enable `zoom-canvas` for wheel zoom and `drag-canvas` to pan by dragging empty space. Omitting `behaviors` enables both.

Set wheel speed with `sensitivity` and its limits with `minZoom` and `maxZoom`. Set `ignoreModifierKeys` to `true` to reserve modified drags for brush or lasso selection.

## Example

Use the wheel over the canvas and watch the current zoom in the bottom-left corner. Drag empty space with the left mouse button to pan.
