---
title: Combos
description: Group nodes with nested, collapsible, draggable combo containers
---

Combo capabilities are experimental during `0.1.x`.

See [Basic appearance and local overrides](/en/docs/api/options/combo#basic-appearance-and-local-overrides) for fields, defaults, units, callbacks, and matching previews. Padding arrays currently apply their maximum uniformly, rather than setting each side separately.

See the [Combo reference](/en/docs/api/options/combo) for complete data fields, node membership, initial collapse and states, and matching code with live results. Existing appearance and runtime usage remain below.

```ts
const graph = new Graph({
  container: '#container',
  data: {
    nodes: [
      { id: 'n1', comboId: 'frontend' },
      { id: 'n2', comboId: 'frontend' },
    ],
    edges: [],
    combos: [{ id: 'frontend', data: { label: 'Frontend' } }],
  },
  combo: { style: { padding: 24, fill: 'rgba(22,119,255,0.06)' } },
});
```

Use `collapseCombo()`, `expandCombo()`, and `toggleCombo()` for visibility. Runtime grouping APIs include `addToCombo()`, `removeFromCombo()`, `createCombo()`, and `removeCombo()`.
