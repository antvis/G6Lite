## What is a layout?

A layout determines where nodes go. A workflow can run left to right, while a force-directed layout can bring connected nodes together. Omit `layout` to use the nodes’ existing `x` and `y` coordinates.

## Choose a layout

| Type | Description | Example configuration |
| --- | --- | --- |
| [`force`](/en/docs/guides/layout-force) | Bring linked nodes closer while spacing nodes apart. | `{ type: 'force', linkDistance: 100 }` |
| [`d3-force`](/en/docs/guides/layout-d3-force) | Arrange a network with D3 force simulation. | `{ type: 'd3-force', linkDistance: 100 }` |
| [`force-atlas2`](/en/docs/guides/layout-force-atlas2) | Use force simulation to reveal network clusters. | `{ type: 'force-atlas2', kr: 12, kg: 0.5 }` |
| [`fruchterman`](/en/docs/guides/layout-fruchterman) | Spread nodes using attraction and repulsion. | `{ type: 'fruchterman', gravity: 4 }` |
| [`grid`](/en/docs/guides/layout-grid) | **External.** Arrange nodes in rows and columns. | `{ type: GridLayout, cols: 3 }` |
| [`circular`](/en/docs/guides/layout-circular) | **External.** Arrange nodes along a circle. | `{ type: CircularLayout, radius: 100 }` |
| [`dagre`](/en/docs/guides/layout-dagre) | **External.** Arrange steps or dependencies in layers. | `{ type: DagreLayout, rankdir: 'LR', ranksep: 80 }` |
| [`concentric`](/en/docs/guides/layout-concentric) | **External.** Arrange nodes in concentric rings by degree. | `{ type: ConcentricLayout, sortBy: 'degree' }` |
| [`radial`](/en/docs/guides/layout-radial) | **External.** Arrange nodes in rings by graph distance from a focal node. | `{ type: RadialLayout, focusNode: '0', unitRadius: 68 }` |
| [`mds`](/en/docs/guides/layout-mds) | **External.** Approximate graph distances in two dimensions. | `{ type: MDSLayout, linkDistance: 80 }` |
| [`indented`](/en/docs/guides/layout-indented) | **External.** Arrange a tree as an indented list. | `{ type: IndentedLayout, indent: 80, rowHeight: 40 }` |
| [`mindmap`](/en/docs/guides/layout-mindmap) | **External.** Arrange a tree as mind map branches. | `{ type: MindmapLayout, levelGap: 120, nodeGap: 30 }` |
| [`fishbone`](/en/docs/guides/layout-fishbone) | **External.** Arrange categories and items along a fishbone spine. | `{ type: FishboneLayout, categoryGap: 180 }` |
| [`random`](/en/docs/guides/layout-random) | **External.** Scatter nodes randomly within an area. | `{ type: RandomLayout, width: 800, height: 600, center: [400, 300] }` |

Pass these configuration objects to `layout`. See [Common layout options](/en/docs/guides/layout) for more parameters and previews.

## Built-in and external layouts [#builtin-and-external-layouts]

G6Lite bundles only four force-directed layouts for large-scale graph analysis: `force`, `force-atlas2`, `d3-force`, and `fruchterman`. Use their string names directly.

Other `@antv/layout` algorithms (such as `grid`, `circular`, `dagre`, and `concentric`) are not bundled. Import the layout class from `@antv/layout` and pass it as `layout.type`:

```ts
import { Graph } from '@antv/g6-lite';
import { DagreLayout } from '@antv/layout';

const graph = new Graph({
  container: '#container',
  data,
  layout: { type: DagreLayout, rankdir: 'LR', ranksep: 80 },
});
```

You can also pass the class directly without an options object: `layout: DagreLayout`.

External layout classes run on the main thread and do not support Workers.

## Other layouts [#optional-layouts]

Indented, Mindmap, Fishbone, Radial, MDS, and Random are also external layouts. Import their classes directly from `@antv/layout`; no registration is required. This example uses Radial:

```ts
import { RadialLayout } from '@antv/layout';

const layout = { type: RadialLayout, focusNode: '0', unitRadius: 68 };
```

These layout classes also run on the main thread.

## Configuration and example

Set the algorithm with `layout.type`. This example uses Dagre to arrange three steps from left to right.

```ts
import { Graph } from '@antv/g6-lite';
import { DagreLayout } from '@antv/layout';

const graph = new Graph({
  container: '#container',
  data: {
    nodes: [{ id: 'Submit' }, { id: 'Review' }, { id: 'Publish' }],
    edges: [
      { source: 'Submit', target: 'Review' },
      { source: 'Review', target: 'Publish' },
    ],
  },
  layout: { type: DagreLayout, rankdir: 'LR', ranksep: 80 },
  node: { style: { label: (node) => node.id } },
});

await graph.render();
```
