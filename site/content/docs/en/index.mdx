## Core capabilities

WebGL draws nodes and edges, while Canvas 2D presents labels and groups. G6Lite includes layouts, states, incremental updates, and controlled extensions. See [product positioning](/en/docs/concepts/overview) for workload boundaries and [architecture](/en/docs/concepts/architecture) for internals.

## Choosing G6Lite

For blank canvases, zoom, or interaction issues, start with the [FAQ](/en/docs/faq) and [runtime requirements](/en/docs/compatibility/browser). Evaluate large graphs with [performance metrics](/en/docs/metrics/performance) and [tuning](/en/docs/metrics/performance-tuning). Existing G6 projects should read the [migration guide](/en/docs/compatibility/g6-v5-migration).
