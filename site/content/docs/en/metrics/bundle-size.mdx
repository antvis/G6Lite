title: Bundle size
description: Reproduce the size-limit measurement and enforce the 120 kB brotli budget
---

G6-GL measures the `dist/index.js` package entry and reachable dependencies with size-limit. The default package keeps the **120 kB minified and brotli-compressed budget**, with a separate 90 kB budget for the rendering core without layout algorithms.

```bash
npm run build
npm run size
```

The 2026-07-30 workspace result is **83.18 kB / 90 kB** for core and **109.69 kB / 120 kB** for the default entry. Dagre, radial, and MDS are explicit optional subpaths and are not included in the default package gauge. Run the command on the current checkout for the latest result.

Import from the package root, use a tree-shaking bundler, enable production compression, and inspect the final application bundle. Do not compare libraries unless feature scope and dependency boundaries are equivalent.
