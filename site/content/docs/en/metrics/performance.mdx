This comparison covers G6Lite, G6, Sigma.js, and the ECharts Graph series. All renderers receive the same precomputed positions, and all bundles use the same build settings. The 2026-11-13 run used a locally packaged G6Lite `0.1.0` build.

## First-draw timing [#render-time]

The table shows the median time in milliseconds from graph creation through two animation frames after the render API completes. Headless Chromium uses the SwiftShader software renderer for WebGL in this run.

| npm package | Renderer | 1,000 nodes / 3,000 edges (ms) | 5,000 nodes / 15,000 edges (ms) |
| --- | --- | ---: | ---: |
| `@antv/g6-lite@0.1.0` | WebGL | 134.1 | 146.1 |
| `@antv/g6@5.1.1` | Canvas 2D | 297.4 | 1,502.2 |
| `sigma@4.0.4` + `graphology@0.26.0` | WebGL 2 | 466.1 | 748.4 |
| `echarts@6.1.0` | Canvas 2D | 56.6 | 236.3 |

### Test conditions [#benchmark-method]

- Apple M3 Pro, macOS (Darwin 25.2.0), headless Chromium 151.0.7922.34. The canvas is 900 × 600 CSS pixels at DPR 1. The WebGL renderer reports `ANGLE (Google, Vulkan 1.3.0 (SwiftShader Device (LLVM 10.0.0) (0x0000C0DE)), SwiftShader driver)`.
- Each library receives the same nodes, edges, and fixed positions. The graphs use circular nodes and straight edges, with labels and animation disabled and no layout run. For each size, each library warms up 3 times, then runs 20 interleaved samples. The instance is disposed after each sample.
- Libraries are loaded before timing. Samples cover instance and internal model creation, the first render, and two animation frame callbacks. Sigma.js includes building the Graphology graph. Measure GPU execution, layout, and interactions separately. [Download raw samples](/benchmarks/graph-performance.json)

These results apply only to the environment above and do not certify minimum supported browser versions. See [Minimum browser versions](/en/docs/compatibility/browser#minimum-browser-versions) for capability version references and the remaining acceptance scope.

## Browser bundle size [#bundle-size]

esbuild 0.21.5 bundles each npm entry and its dependencies into a single minified browser script. The G6Lite measurement uses the default entry, with optional layouts imported separately as needed. ECharts imports GraphChart and CanvasRenderer only. Sigma.js includes Graphology. Sizes are in KiB and exclude source maps.

| npm package | Minified (KiB) | gzip -9 (KiB) |
| --- | ---: | ---: |
| `@antv/g6-lite@0.1.0` | 511.3 | 159.5 |
| `@antv/g6@5.1.1` | 1,435.3 | 413.4 |
| `sigma@4.0.4` + `graphology@0.26.0` | 438.4 | 110.7 |
| `echarts@6.1.0` | 386.3 | 130.2 |

### G6Lite CDN file sizes [#umd-size]

Each CDN file is measured with `gzip -9`. One kB is 1,000 bytes. The homepage shows the size of the default script.

| Published file | Contents | gzip -9 (kB) |
| --- | --- | ---: |
| `g6-lite.min.js` | Default script with rendering, interactions, and built-in layouts | 150.2 |
| `g6-lite-layouts.min.js` | Six optional layouts, loaded when needed | 29.1 |

Load the optional script before registering the layout you want to use. [Optional layouts](/en/docs/guides/layout-overview#optional-layouts)

## Measuring your own graph [#performance-tuning]

Use production data and target devices to measure layout, first draw, and interactions separately. For a slow startup, isolate layout from drawing before assessing Worker execution. For slow updates, reuse the graph and update data or states incrementally. For frame drops during zoom, compare labels, decorations, and viewport size one at a time. Check disposal and listener cleanup after repeated mounts.
