## 运行与源码

- <a href={withBasePath('/playground/')}>打开在线 Playground</a>
- [查看全部示例源码](https://github.com/antvis/G6Lite/tree/master/playground/demos)

本地开发时运行：

```bash
npm run dev
```

然后通过 `http://localhost:5173/#<demo-id>` 打开指定案例。
