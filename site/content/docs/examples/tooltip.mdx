这个示例展示内置 `tooltip` behavior。Tooltip 内容通过 `getContent` 生成，可以针对节点和边分别返回不同 HTML。

## 代码

```ts
const graph = new Graph({
  container,
  data,
  layout: { type: 'force', maxIteration: 300 },
  behaviors: [
    'zoom-canvas',
    'drag-canvas',
    'highlight-node',
    {
      type: 'tooltip',
      trigger: 'hover',
      getContent: (ctx) => {
        if (ctx.itemType === 'node') {
          const { label, role } = ctx.data ?? {};
          return `<b>${label ?? ctx.nodeId}</b><br/>${role ?? ''}`;
        }
        return `${ctx.source} -> ${ctx.target}`;
      },
    },
  ],
});

await graph.render();
```
