**Combo** 是节点的分组容器，用于把一组节点圈在一个可视的包围框内，支持嵌套、折叠 / 展开，以及作为整体拖拽。Combo 包围框由 Canvas 2D 在 WebGL 画布下方叠加绘制，不影响节点 / 边的 GPU 渲染性能。

## 声明 Combo

Combo 通过两处声明：在 `data.combos` 中定义分组，在节点上用 `comboId` 指定归属。

```ts
import { Graph } from '@antv/g6-lite';

const graph = new Graph({
  container: 'container',
  data: {
    nodes: [
      { id: 'n1', comboId: 'frontend' },
      { id: 'n2', comboId: 'frontend' },
      { id: 'n3', comboId: 'backend' },
      { id: 'n4', comboId: 'database' },
      { id: 'n5' }, // 不属于任何 combo
    ],
    edges: [
      { source: 'n1', target: 'n3' },
      { source: 'n3', target: 'n4' },
    ],
    combos: [
      { id: 'frontend', data: { name: 'Frontend' } },
      { id: 'backend', data: { name: 'Backend' } },
      // 嵌套：database 是 backend 的子 combo
      { id: 'database', parentId: 'backend', data: { name: 'Database' } },
    ],
  },
  layout: { type: 'd3-force' },
  behaviors: ['zoom-canvas', 'drag-canvas', 'drag-node', 'click-select'],
});

await graph.render();
```

### ComboData 字段

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| **id** | `string` | Combo 唯一标识（必填） |
| **parentId** | `string` | 父 Combo id，用于嵌套 |
| **style** | `Partial<ComboStyleConfig>` | 单个 Combo 的样式覆盖 |
| **data** | `Record<string, unknown>` | 业务扩展数据，可在样式函数中读取 |

## 样式配置

全局 Combo 样式通过 `GraphOptions.combo.style` 设置，支持函数形式按 Combo 取值：

```ts
const graph = new Graph({
  // ...
  combo: {
    style: {
      fill: 'rgba(100, 150, 255, 0.06)',
      stroke: 'rgba(100, 150, 255, 0.3)',
      strokeWidth: 1,
      borderRadius: 12,
      padding: 30,
      label: (combo) => (combo.data as Record<string, string>)?.name ?? combo.id,
      labelPlacement: 'top',
      labelFontSize: 13,
      labelColor: 'rgba(0, 0, 0, 0.65)',
    },
  },
});
```

### ComboStyleConfig 字段

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| **fill** | `string \| (combo) => string` | 包围框填充色 |
| **stroke** | `string \| (combo) => string` | 边框颜色 |
| **strokeWidth** | `number` | 边框宽度 |
| **opacity** | `number` | 不透明度 |
| **borderRadius** | `number` | 圆角半径 |
| **padding** | `number \| [number, number, number, number]` | 包围框内边距 |
| **label** | `string \| (combo) => string` | 分组标签文本 |
| **labelFontSize** | `number` | 标签字号 |
| **labelColor** | `string` | 标签颜色 |
| **labelPlacement** | `'top' \| 'bottom' \| 'inside'` | 标签位置 |
| **collapsedSize** | `number` | 折叠后包围框的尺寸 |

## 折叠与展开

折叠后，Combo 收缩为一个小块，其内部节点与边隐藏；展开则还原。

```ts
graph.collapseCombo('frontend'); // 折叠
graph.expandCombo('frontend');   // 展开
graph.toggleCombo('frontend');   // 切换

// 折叠 / 展开会触发事件
graph.on('combo:collapse', ({ id }) => console.log('collapsed', id));
graph.on('combo:expand', ({ id }) => console.log('expanded', id));
```

## 动态调整归属

```ts
// 把节点 n5 加入 frontend 分组
graph.addToCombo('n5', 'frontend');

// 把节点移出其所在分组
graph.removeFromCombo('n5');

// 动态新建一个 combo，并把若干节点放进去
graph.createCombo({ id: 'newGroup', data: { name: 'New' } }, ['n1', 'n2']);

// 删除一个 combo（其子节点回到无分组状态）
graph.removeCombo('newGroup');

// 改完数据后触发重绘
graph.scheduleRender();
```

## 查询

```ts
graph.getComboData('frontend');     // 返回 InternalCombo（含计算后的 x/y/width/height）
graph.getComboChildren('backend');  // { nodes: string[], combos: string[] }
graph.getNodeCombo('n1');           // 节点所属 combo id
```

## 整体拖拽

启用 `drag-node` 后，拖拽 Combo 区域会带动其所有子节点一起移动，并触发 `combo:dragstart` / `combo:drag` / `combo:dragend` 事件。配合 `click-select` 可先多选节点再整体拖拽。

```ts
behaviors: ['zoom-canvas', 'drag-canvas', 'drag-node', 'click-select']

graph.on('combo:dragend', ({ id }) => console.log('moved combo', id));
```
