先按能力查契约；按步骤开发看[扩展体系](/docs/guides/extensions)。绘制类与运行类的生命周期不同，不把字段、教程和实例作用域混为一份定义。

## `register()`

注册重载、名称约束、覆盖、兼容形式与类型见[注册与上下文](/docs/api/extensions/registration#register)。

| 类别 | 激活位置 | 完整公共协议 |
| --- | --- | --- |
| node | node.type | [NodeExtension](/docs/api/extensions/drawing#nodeextension) |
| edge | edge.type | [EdgeExtension](/docs/api/extensions/drawing#edgeextension) |
| label | node / edge.labelRenderer | [LabelRenderer](/docs/api/extensions/drawing#labelrenderer) |
| decoration | node.decorations[].renderer | [DecorationRenderer](/docs/api/extensions/drawing#decorationrenderer) |
| behavior | behaviors | [BehaviorExtension](/docs/api/extensions/runtime#behaviorextension) |
| layout | layout.type | [LayoutExtension](/docs/api/extensions/runtime#layoutextension) |
| transform | transforms | [TransformExtension](/docs/api/extensions/runtime#transformextension) |
| plugin | plugins | [PluginExtension](/docs/api/extensions/runtime#pluginextension) |

Transform / Plugin 的配置形状、顺序与更新边界见[配置参考](/docs/api/options/transforms-plugins)。

## `extensionFactory()`

标记工厂不等于立即创建实例，也不统一每个 Graph 一次。完整签名、注册形式与缓存/实例作用域见[工厂契约](/docs/api/extensions/registration#extensionfactory)。

## 扩展上下文

快照字段、数据写入、状态替换、坐标、调度和销毁状态统一定义于[ExtensionContext](/docs/api/extensions/registration#extensioncontext)。运行钩子的输入和完成时机见[运行契约](/docs/api/extensions/runtime)。

## `runLayout()`

独立计算的签名、视口、取消信号和示例见[runLayout](/docs/api/graph/layout#runlayout)，已有 Graph 重排用[布局方法](/docs/api/graph/layout)。独立计算不调用 Layout.init；实现步骤见[自定义布局](/docs/guides/custom-layout)。
