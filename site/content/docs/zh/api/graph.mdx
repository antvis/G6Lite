Graph 操作一张图。选择下面的任务，点击方法名查询参数、返回值、单位、调用时机和边界。创建与订阅可在 render 前完成，常规数据与状态写入等待有效 render。

首次接入见[生命周期](/docs/concepts/graph-lifecycle)，构造参数查[GraphOptions](/docs/api/options)。旧兼容方法与内部边界查[API 稳定性](/docs/compatibility/api-stability)，不纳入推荐方法清单。
