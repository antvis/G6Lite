`Graph` 是业务代码操作一张图的实例。从包根导入后，先传入 [配置](/docs/api/options)，再 `await graph.render()`。

```ts
import { Graph } from '@antv/g6-lite';

const graph = new Graph({ container, data });
await graph.render();
```

数据写入、状态修改和 `layout()` 必须发生在首次 `render()` 成功之后。实例销毁后，这些方法直接返回。

## 生命周期

创建、渲染、销毁与刷新的完整契约见[生命周期方法参考](/docs/api/graph/lifecycle)。阶段选择与清理步骤见[Graph 生命周期](/docs/concepts/graph-lifecycle)。

### `new Graph(options)`

[创建实例](/docs/api/graph/lifecycle#new-graph)：容器、画布归属及 GraphOptions 入口。

### `render()`

[render](/docs/api/graph/lifecycle#render)：等待有效初始化完成，了解重复渲染、事件顺序和取消边界。

### `destroy()`

[destroy](/docs/api/graph/lifecycle#destroy)：销毁实例资源；业务请求、计时器和 DOM 监听由业务清理。

### `destroyed`

[destroyed](/docs/api/graph/lifecycle#destroyed)：只读销毁标记，不等于渲染成功或任务有效。

### `refresh()`

[refresh](/docs/api/graph/lifecycle#refresh)：重算样式并绘制，不重新初始化、布局或适配。

## 替换数据与样式

### `setData()`

[setData](/docs/api/graph/data-mutations#setdata) 替换全图，参数、视野、取消和失败边界见写入参考；流程与代码效果见[数据指南](/docs/guides/data)。

### `updateOptions()`

[updateOptions](/docs/api/graph/lifecycle#updateoptions) 更新 node、edge、label 和 theme；对象、函数和状态样式的合并规则见方法参考。它不接受布局、行为或插件配置；更换布局使用 [setLayout + layout](/docs/api/graph/layout)。

## 修改节点和边

首次有效 render 后使用，完整签名和批量边界见[数据写入参考](/docs/api/graph/data-mutations)。

### 节点

[addNode(s)](/docs/api/graph/data-mutations#addnode) · [updateNodeData](/docs/api/graph/data-mutations#updatenodedata) · [updateNodePosition(s)](/docs/api/graph/data-mutations#updatenodeposition) · [removeNode(s)](/docs/api/graph/data-mutations#removenode)

新增提供坐标；数据浅合并；删除节点会删除关联边，不重布局或适配。

### 边

[addEdge(s)](/docs/api/graph/data-mutations#addedge) · [updateEdgeData](/docs/api/graph/data-mutations#updateedgedata) · [removeEdge(s)](/docs/api/graph/data-mutations#removeedge)

新增返回实际 ID，批量更新可改端点，删除边不会删除节点。

## 状态、显隐和定位

增减、替换、查询、清空与显隐的完整契约见[状态与显隐方法参考](/docs/api/graph/states)；按业务任务操作见[状态使用指南](/docs/guides/states)。

### `setItemState()`

[增减一个状态](/docs/api/graph/states#setitemstate)，保留其他标记。

### `setElementStates()`

[替换完整状态集合](/docs/api/graph/states#setelementstates)，支持单 id 和状态映射。

### `batchSetState()`

[批量增减状态](/docs/api/graph/states#batchsetstate)，可混合节点、边和 Combo。

### 查询和清空

[getItemStates](/docs/api/graph/states#getitemstates) 读取快照；[findNodesByState](/docs/api/graph/states#findnodesbystate)、[findEdgesByState](/docs/api/graph/states#findedgesbystate)、[findCombosByState](/docs/api/graph/states#findcombosbystate) 查询对应 ID；[clearItemStates](/docs/api/graph/states#clearitemstates) 清空业务状态。

### `hideItem()` 与 `showItem()`

[hideItem](/docs/api/graph/states#hideitem) 和 [showItem](/docs/api/graph/states#showitem) 增减 hidden；关联元素与折叠隐藏的边界见新参考中的代码与效果。

### `focusItem()`

[focusItem](/docs/api/graph/viewport#focusitem) 定位一个或多个节点；目标范围、缩放和 padding 规则见视口方法参考。

## 视口

相机、缩放、适配、定位、尺寸与坐标转换的完整契约见[视口方法参考](/docs/api/graph/viewport)。任务步骤见[视口指南](/docs/guides/viewport)，坐标关系见[核心概念](/docs/concepts/viewport)。

相机查询与恢复：[getCamera](/docs/api/graph/viewport#getcamera) · [setCamera](/docs/api/graph/viewport#setcamera) · [resetCamera](/docs/api/graph/viewport#resetcamera)。

### 容器尺寸变化

[setSize](/docs/api/graph/viewport#setsize) 同步画布尺寸；容器 CSS 变化由 ResizeObserver 自动处理。[autoFit](/docs/api/options#autofit) 决定尺寸变化后是否适配，resize 在可选适配后发出。宽度切换效果见[实时示例](/docs/api/graph/viewport#容器变宽变窄后的适配)。

### `zoomTo()` 与 `zoomBy()`

[getZoom](/docs/api/graph/viewport#getzoom) 查询缩放；[zoomTo](/docs/api/graph/viewport#zoomto) 设置绝对值，[zoomBy](/docs/api/graph/viewport#zoomby) 乘当前值。中心和 ZoomOptions 查方法参考；滚轮范围查 [Behavior](/docs/api/options/behaviors#导航与拖拽)。

### `fitView()`

[fitView](/docs/api/graph/viewport#fitview) 调整缩放和平移；[fitCenter](/docs/api/graph/viewport#fitcenter) 保持缩放只居中。刷新后保留视野见[使用指南](/docs/guides/viewport#刷新数据保留或重新适配)。

### 坐标转换

[screenToGraph](/docs/api/graph/viewport#screentograph) 从 client CSS 坐标转到图坐标；[graphToScreen](/docs/api/graph/viewport#graphtoscreen) 反向转换。实时观察与 DOM 定位见[坐标指南](/docs/guides/viewport#转换坐标定位-dom-内容)。

## 布局

- [元素载荷](/docs/api/graph/events#元素事件载荷)、[选择](/docs/api/graph/events#选择事件)、[拖拽](/docs/api/graph/events#拖拽事件)：完整字段与触发条件。
