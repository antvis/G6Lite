业务代码从 @antv/g6-lite 包根导入。总览帮助选择查询入口，完整签名、字段与行为统一维护在对应参考页；开发步骤看[使用指南](/docs/guides/data)或[扩展总览](/docs/guides/extensions)。

```ts
import { Graph, register, extensionFactory, runLayout, resolveTheme, EventEmitter } from '@antv/g6-lite';
import type { GraphOptions, GraphData, GraphEventMap } from '@antv/g6-lite';
```

## 可以直接使用的入口

| 入口 | 用途 | 查询位置 |
| --- | --- | --- |
| Graph | 操作一张图 | [按任务查询全部公开成员](/docs/api/graph) |
| GraphOptions 与主题配置类型 | 声明构造配置 | [顶层字段与分主题入口](/docs/api/options) |
| register / extensionFactory | 注册扩展与创建隔离实例 | [注册、工厂与作用域](/docs/api/extensions/registration) |
| runLayout | 独立计算节点坐标 | [工具函数](/docs/api/utilities#runlayout) |
| resolveTheme | 解析预设与 token | [工具函数](/docs/api/utilities#resolvetheme) |
| EventEmitter / Handler | 应用自己的事件分发 | [独立事件工具](/docs/api/utilities#eventemitter) |

图事件使用 [Graph.on / off / once](/docs/api/graph/events)，扩展实例作用域按类别确定，不统一“每个 Graph 一次”。

## 调用顺序

首次创建、事件订阅、有效 render 与卸载清理见[Graph 生命周期](/docs/concepts/graph-lifecycle)，精确前提见[生命周期方法](/docs/api/graph/lifecycle)。运行环境、模块格式和客户端要求见[浏览器与运行环境](/docs/compatibility/browser)与[ESM / CommonJS 边界](/docs/compatibility/api-stability#esm-与-commonjs)。

## 读取结果不能直接改

查询 Model 是只读类型的实时视图，getData 是分层浅复制的导出快照。变更通过数据或状态 API，完整复制规则见[数据读取](/docs/api/graph/data)，任务选择见[数据指南](/docs/guides/data)。

## 引擎内部方法

类上出现的内部成员不属于业务 API；不要直接依赖渲染器、拾取或内部事件分发。具体边界与公开替代入口统一查[公开与内部边界](/docs/compatibility/api-stability#公开与内部边界)。

## 已有项目里的兼容入口

BaseNode、BreathingNode、registerNode 及弃用方法仅保留给已有项目；完整名称和替代方式统一查[弃用兼容层](/docs/compatibility/api-stability#弃用兼容层)。升级规则与实验能力也在稳定性页维护。
