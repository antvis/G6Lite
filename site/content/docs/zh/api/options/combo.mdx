全局入口：`GraphOptions.combo.style`；单组覆盖：`data.combos[].style`。按任务查阅[数据](#combodata)、[基础外观](#基础外观与局部覆盖)、[折叠形态](#折叠形态)、[状态样式](#状态样式)。操作步骤见 [Combo 指南](/docs/guides/combo)。

嵌套、折叠和运行时归组属于[实验性能力](/docs/compatibility/api-stability#实验性能力)，可能在 `0.1.x` 内调整。`ComboConfig` 当前只有 `style?: ComboStyleConfig`。

## ComboData

用 `GraphData.combos?: ComboData[]` 声明分组，节点通过 `comboId` 加入。边的 source、target 仍指向节点 id。

| 字段 | 类型 | 必填 | 默认与规则 |
| --- | --- | --- | --- |
| `id` | `string` | 是 | 唯一标识；避免与节点、边 id 重复 |
| `parentId` | `string` | 否 | 无父级；引用同一 combos 数组内的父 Combo |
| `collapsed` | `boolean` | 否 | `false`；[初始折叠](#初始折叠) |
| `style` | `Partial<ComboStyleConfig>` | 否 | 覆盖全局样式中的同名字段 |
| `data` | `Record<string, unknown>` | 否 | 业务数据，不自动转成标签或布局参数 |
| `states` | `ElementState[]` | 否 | 空状态集合；读取时为去重后的 Set |

### 节点归属与嵌套

- 节点的 `comboId` 指定直接归属；Combo 的 `parentId` 指定父级。成员集合由引擎计算。
- 父级可后声明，但引用须有效、层级须无环。无效引用当前被忽略，应由业务校验。
- 边界由成员位置、尺寸、子分组与 padding 计算；不接受 x/y、width/height。空分组不绘制占位框。

## 初始折叠

`collapsed: true` 隐藏后代节点及其关联边，不生成虚拟边；`states: ['collapsed']` 不触发折叠。外观字段见[折叠形态](#折叠形态)，运行时操作见[折叠与展开](/docs/guides/combo#折叠与展开)。

<details>
<summary>嵌套折叠与 hidden 的边界</summary>

子 Combo 边框不会随祖先折叠自动隐藏。展开会保留节点、边原有的业务 hidden；多个折叠祖先共同控制成员可见性，展开一个祖先不一定恢复显示。

</details>

## 初始状态

`states` 声明初始状态，外观由[状态样式](#状态样式)控制。`hidden` 只隐藏分组自身，不级联隐藏成员。内置 `click-select` 只处理节点和边；Combo 选择需调用状态 API，见下方可交互示例。

## 只读查询模型

首次 `await graph.render()` 后，`getComboData(id)` 返回 `ComboModel | undefined`。返回值只读，更新请用[Combo 方法](/docs/api/graph/combo)或[状态方法](/docs/api/graph/states)。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `id` / `parentId` | `string` / `string \| undefined` | 身份与父级 |
| `childNodeIds` | `ReadonlySet<string>` | 直接成员节点，不含子分组内节点 |
| `childComboIds` | `ReadonlySet<string>` | 直接子分组 |
| `collapsed` | `boolean` | 当前折叠状态 |
| `x` / `y` | `number` | 包围框中心，图坐标 |
| `width` / `height` | `number` | 包围框尺寸，非折叠图形尺寸 |
| `style` | `Readonly<Partial<ComboStyleConfig>> \| undefined` | 局部输入，非合成后的最终样式 |
| `data` | `Readonly<Record<string, unknown>> \| undefined` | 业务数据 |
| `states` | `ReadonlySet<ElementState>` | 当前状态 |

```ts
const group = graph.getComboData('client');
const directChildren = graph.getComboChildren('platform');
const membership = graph.getNodeCombo('web'); // 'client'
const selected = group?.states.has('selected');
```

<details>
<summary>包围框更新与数据导出</summary>

包围框随渲染重算，归属变更后的查询不保证几何已同步更新。`getData()` 导出当前归属、parentId、collapsed、states，不把折叠产生的 hidden 当作业务 hidden 导出；样式函数不能直接持久化为 JSON。

</details>

## 基础外观与局部覆盖

全局设在 `combo.style`，单组设在 `data.combos[].style`；两处共用以下字段。

### 基础样式字段

| 字段 | 类型 | 默认值 | 规则 |
| --- | --- | --- | --- |
| `fill` | `ComboStyleValue<string>` | `'rgba(100, 150, 255, 0.08)'` | Canvas 颜色；`'transparent'` 关闭底色 |
| `stroke` | `ComboStyleValue<string>` | `'rgba(100, 150, 255, 0.3)'` | Canvas 描边颜色 |
| `strokeWidth` | `ComboStyleValue<number>` | `1` | 屏幕像素，不随 zoom 加粗 |
| `opacity` | `ComboStyleValue<number>` | `1` | 0–1；仅影响分组底色、描边和标签 |
| `borderRadius` | `ComboStyleValue<number>` | `8` | 展开圆角，图坐标单位；不超过边框宽高的一半 |
| `padding` | `number \| [number, number, number, number]` | `20` | 图坐标单位；数组取最大值用于四周；不支持回调 |
| `label` | `ComboStyleValue<string \| false>` | 不绘制展开标签 | `false` 或空串隐藏；不自动读取 id/data.name |
| `labelFontSize` | `ComboStyleValue<number>` | `12` | 缩放前字号，CSS 像素 |
| `labelColor` | `ComboStyleValue<string>` | `'rgba(0, 0, 0, 0.65)'` | 标签颜色 |
| `labelPlacement` | `'top' \| 'bottom' \| 'inside' \| 'center'` | `'top'` | 展开标签位置；不支持回调 |

<details>
<summary>数值范围、主题与标签缩放</summary>

颜色使用有效 Canvas 颜色；尺寸、线宽、字号使用有限正数，padding 与 borderRadius 使用有限非负数。无统一的无效值清洗，也没有主题 token 注入。

描边按 DPR 处理。展开字号为 `labelFontSize * DPR * min(zoom, 1.5)`，小于 6 绘制像素时不显示。

</details>

### 字段回调与覆盖顺序

`ComboStyleValue<T> = T | ((combo: ComboModel) => T)`。回调只接收分组模型，可读 data、直接成员集合和状态；保持轻量，不修改模型。

按字段合并：**全局基础 → 局部基础 → 已激活的状态覆盖 → 解析最终回调**。局部常量或函数替换同名全局值；undefined 不清除全局值。状态间顺序见[状态样式](#状态样式)。

### 留白、包围框与标签

- `[8, 40, 12, 24]` 等同于四周 `40`，不按 CSS 四方向计算；padding 不支持状态覆盖。
- 边界包含节点主体与子分组，不测量标签。父分组在子分组边界外再加自己的留白。
- top/bottom 在框外居中，inside 在左上内侧，center 在框中心。标签不换行、不截断、不避让，不使用节点/边的 LabelOptions。

### 运行时修改边界

局部样式通过数据快照替换；`updateOptions()` 当前不接受 combo。

```ts
const data = graph.getData();
const group = data.combos?.find((combo) => combo.id === 'local');
if (group) {
  group.style = { ...group.style, fill: 'rgba(22,160,133,0.12)' };
  await graph.setData(data, { fitView: false });
}
```

这会替换全部数据并重跑已配置的布局；`fitView: false` 只保留视口。全局样式需重建实例；临时高亮用[状态 API](/docs/api/graph/states)。

## 折叠形态

以下字段均位于 `combo.style` 或单组 `style`，只控制折叠后的外观。

| 字段 | 类型 | 默认值 | 规则 |
| --- | --- | --- | --- |
| `collapsedType` | `'circle' \| 'rect'` | `'circle'` | 圆形或圆角矩形；不支持回调 |
| `collapsedSize` | `ComboStyleValue<number \| [number, number]>` | `30` | 图坐标尺寸；数值表示等宽高，元组表示宽高 |
| `size` | `ComboStyleValue<number \| [number, number]>` | 无 | collapsedSize 的回退别名；两者都有时 collapsedSize 优先 |
| `count` | `boolean \| string \| ((combo: ComboModel) => boolean \| string)` | `true` | true 递归计数后代节点；false 隐藏；字符串显示自定义文本 |

**文字优先用 label，再用 count。** 显式 `label: false` 或空串也会关闭计数。文字固定居中，labelPlacement 不生效。

<details>
<summary>折叠尺寸与文字的绘制细节</summary>

图形随 zoom 缩放，圆形以宽高较小值为直径，不生成椭圆。矩形圆角最多为 8 屏幕像素，不使用 borderRadius。位置沿用已计算的分组中心；空分组仍不绘制。

文字无换行、截断或碰撞处理。绘制半径大于 8 像素才显示文字；字号为 `max(10 * DPR, min(labelFontSize * DPR, 半径 * 0.7))`。自动 count 包含子分组内节点；`childNodeIds.size` 仅含直接成员。

</details>

## 状态样式

入口：`combo.style.stateStyles` 或 `ComboData.style.stateStyles`；类型为 `Partial<Record<ElementState, ComboStateStyleOverride>>`。每个状态可覆盖以下 **8 个字段**，省略的字段沿用已有值：

| 字段 | 类型 | 覆盖内容 |
| --- | --- | --- |
| `fill` | `ComboStyleValue<string>` | 底色 |
| `stroke` | `ComboStyleValue<string>` | 描边颜色 |
| `strokeWidth` | `ComboStyleValue<number>` | 描边宽度 |
| `opacity` | `ComboStyleValue<number>` | 分组整体透明度 |
| `borderRadius` | `ComboStyleValue<number>` | 展开圆角 |
| `label` | `ComboStyleValue<string \| false>` | 标签或关闭文字 |
| `labelFontSize` | `ComboStyleValue<number>` | 字号 |
| `labelColor` | `ComboStyleValue<string>` | 文字颜色 |

合并顺序：**active → highlight → selected → disabled → inactive**；每个状态内先全局、后局部，后合并的同名字段优先。状态覆盖不支持 padding、折叠尺寸或 labelPlacement。

示例显式监听 `combo:click` 切换 selected；最后一组保留 inactive，可对比叠加效果。

<ComboDocExample id="combo-states" locale="zh" />

<details>
<summary>未配置样式时的效果与自定义状态</summary>

- selected 未配置时追加蓝色 2 屏幕像素描边；active/highlight 未配置时追加蓝色 1.5 像素描边，selected 回退优先。
- 显式 selected 样式（含空对象）关闭对应回退；只要配置 active 或 highlight 任一项，就关闭这两者的回退描边。
- disabled/inactive 没有自动变灰效果，需显式配置。自定义状态名会保存，但当前不参与内置样式合成；default 同样不参与上述覆盖。
- hidden 跳过分组自身绘制与命中，不隐藏成员；与 collapsed 相互独立。

</details>
