`GraphOptions.node` 的类型是 `NodeConfig`。本页详细说明顶层选项、基础外观、标签、图标、装饰与状态。配置步骤与效果见[节点指南](/docs/guides/node)。

```ts
import type { NodeConfig } from '@antv/g6-lite';

const node: NodeConfig = {
  type: 'rect',
  style: {
    size: 32,
    width: 96,
    height: 40,
    borderRadius: 8,
    fill: (item) => item.data?.risk === 'high' ? '#ff4d4f' : '#1783FF',
    stroke: '#fff',
    strokeWidth: 1,
  },
  stateStyles: {
    selected: { stroke: '#163B65', strokeWidth: 2 },
  },
};
```

将该对象作为 `new Graph({ container, data, node })` 的 `node` 配置。

## NodeConfig

所有顶层字段均可省略。

| 字段 | 类型 | 默认行为与约束 |
| --- | --- | --- |
| `type` | `'circle' \| 'rect' \| string` | 默认 `'circle'`；自定义名称先通过 `register('node', ...)` 注册，实际图元取自扩展的 `base` |
| `style` | `NodeStyleConfig \| ((node: GraphNode) => Partial<NodeStyleConfig>)` | 未配置时使用主题和字段回退值；整对象函数的差异见下文 |
| `stateStyles` | `Partial<Record<ElementState, NodeStateStyleOverride>>` | 按状态覆盖基础外观；未配置的状态使用扩展或主题状态定义 |
| `labelRenderer` | `string` | 默认标签渲染器；指定名称须先注册 label 扩展，且 `style.label` 必须提供非空文本 |
| `decorations` | `NodeDecorationConfig[]` | 默认无装饰；字段见下方 [NodeDecorationConfig](#nodedecorationconfig)，可使用内置 `builtin-badge` 或注册的 decoration 渲染器 |
| `autoExternalLabelPlacement` | `boolean` | 仅类型声明，当前运行时未读取；设置为 `true` 或 `false` 均不会改变布局。请显式设置 `style.labelPlacement` |

未知节点类型当前会回退到圆形基型，但不应依赖此回退代替注册。

## NodeStyleConfig

下表默认值适用于内置节点的 **style 对象**，包括对象中逐字段配置函数的形式。示例中未传 `theme` 时采用 light 预设；自定义主题和节点扩展可改变回退值。

| 字段 | 类型 | 默认或回退 | 说明 |
| --- | --- | --- | --- |
| `fill` | `NodeStyleValue<string>` | `theme.nodeFill`，预设为 `'#1783FF'` | 填充颜色 |
| `size` | `NodeStyleValue<number>` | `theme.nodeSize`，预设为 `24` | 圆形直径；矩形未单独指定宽高时的回退尺寸 |
| `width` | `NodeStyleValue<number>` | 解析后的 `size` | 矩形宽度；不改变内置圆形的直径 |
| `height` | `NodeStyleValue<number>` | 解析后的 `size` | 矩形高度；不改变内置圆形的直径 |
| `stroke` | `NodeStyleValue<string>` | `theme.nodeStroke`；light 为 `'#fff'`，dark 为 `'#333'` | 描边颜色 |
| `strokeWidth` | `NodeStyleValue<number>` | `theme.nodeStrokeWidth`，预设为 `0` | 描边宽度；为 `0` 时不显示描边 |
| `opacity` | `NodeStyleValue<number>` | `1` | 不透明度，使用 `0` 到 `1` |
| `borderRadius` | `NodeStyleValue<number>` | `0` | 矩形圆角；绘制时不超过宽高较小值的一半 |

`size`、`width`、`height`、`strokeWidth` 和 `borderRadius` 使用图坐标长度，随相机缩放。它们不是固定的屏幕 CSS 像素；业务无需自行乘 DPR。只设置 `opacity: 0` 不等同于调用隐藏 API，显隐操作见 [Graph 状态方法](/docs/api/graph#状态显隐和定位)。

### 样式函数

`NodeStyleValue<T>` 为 `T | ((node: GraphNode) => T)`。回调只接收当前节点，业务字段从 `node.data` 读取；无额外的相机或缩放参数。为缺失业务数据提供明确回退，避免返回 `undefined` 或无效数值。

```ts
import type { NodeConfig } from '@antv/g6-lite';

const node: NodeConfig = {
  style: {
    size: (item) => Number(item.data?.size ?? 24),
    fill: (item) => item.data?.group === 'core' ? '#1783FF' : '#61DDAA',
  },
};
```

基础外观的逐字段优先级为：节点 `style` 对象 → 节点扩展的 `getStyle()` 结果 → 扩展默认 `style` → 主题或内置回退。回调应保持轻量且无副作用，不依赖每帧的调用次数。

整对象函数 `style: (node) => ({ ... })` 当前走不同的基础外观解析分支：未返回的 `size`、`width`、`height` 分别回退为 `40`、`100`、`40`，并且该分支未应用 `stateStyles`。需要主题尺寸回退或状态外观时，优先使用上面的逐字段函数。该差异属于当前实现限制，不代表两种写法完全等价。

## 标签

以下字段均位于 `node.style`，支持固定值或 `NodeStyleValue<T>` 回调。

| 字段 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `label` | `NodeStyleValue<string \| false>` | 不绘制 | 标签文本；`false`、空字符串或未配置时均不绘制 |
| `labelFontSize` | `NodeStyleValue<number>` | `12` | 字号，以 CSS 像素为基准，渲染时换算 DPR 与标签缩放 |
| `labelFontFamily` | `NodeStyleValue<string>` | 系统无衬线字体栈 | Canvas 字体族 |
| `labelFontWeight` | `NodeStyleValue<string>` | `'normal'` | Canvas 字重，例如 `'600'` |
| `labelColor` | `NodeStyleValue<string>` | `'#333'` | 文本颜色，未配置时不自动跟随 dark 主题变白 |
| `labelPlacement` | `NodeStyleValue<LabelPlacement>` | `'bottom'` | `'center'`、`'top'`、`'bottom'`、`'left'` 或 `'right'` |
| `labelOffsetX` | `NodeStyleValue<number>` | `0` | 水平偏移，以 CSS 像素为基准，正值向右 |
| `labelOffsetY` | `NodeStyleValue<number>` | `0` | 垂直偏移，以 CSS 像素为基准，正值向下 |
| `labelBackground` | `NodeStyleValue<string \| false>` | `false` | 文字背景色；`false` 关闭背景 |
| `labelBackgroundPadding` | `NodeStyleValue<number>` | `2` | 背景四周内边距，以 CSS 像素为基准 |
| `labelMaxWidth` | `NodeStyleValue<number>` | `0` | 默认渲染器的文字宽度上限；大于 `0` 时超长文字以 `...` 截断，非正值不限宽 |

默认字体栈为 `-apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, "Helvetica Neue", Arial, sans-serif`。相机缩放会影响默认字号、偏移和背景尺寸，但标签缩放有限幅，并非像节点图形一样无限线性放大。需要固定屏幕字号及偏移时，设置 Graph 顶层 `label.scaleWithZoom: false`；无需手动乘 DPR。

默认标签位置参考 `size`。对宽高不同的矩形，需要按实际轮廓精确放置内容时，可以使用自定义 Label Renderer，其锚点会使用渲染宽高。`autoExternalLabelPlacement` 当前不会绕开装饰或移动标签。

标签还受 Graph 顶层 `label` 策略控制：`hideOnLowZoom` 默认 `true`，节点阈值 `nodeMinZoom` 默认 `0.3`；`hideOnCollision` 默认 `true`，与更早标签的文字测量框重叠时隐藏。背景 padding 不会扩大默认文字碰撞框。关闭低缩放隐藏和碰撞隐藏，不会让 `label: false` 的节点显示标签。

### labelRenderer

先通过 `register('label', name, renderer)` 注册，再写 `node.labelRenderer: name`。自定义渲染器仍需非空 `style.label`，并遵循节点标签的低缩放隐藏和碰撞策略。`measure()` 必须返回有限且大于 `0` 的宽高；未注册、非法测量或测量、绘制异常时，当前实现警告并回退默认标签。

引擎传入的 `style` 已转换为 Canvas 像素，`ctx` 已平移到标签锚点；自定义绘制不要重复乘 DPR 或再次叠加节点坐标。自定义渲染器自行消费 `labelMaxWidth` 等外观字段，引擎不替它截断文字。完整签名见[自定义 Label Renderer](/docs/guides/custom-label-renderer)。

## 图标

图标同样配置在 `node.style`，支持固定值或字段回调。

| 字段 | 类型 | 默认值 | 生效条件与单位 |
| --- | --- | --- | --- |
| `icon` | `NodeStyleValue<string \| false>` | 不绘制 | 图片 URL 或文本；含义由 `iconType` 决定，空字符串和 `false` 不绘制 |
| `iconType` | `NodeStyleValue<'image' \| 'text'>` | `'image'` | 图片或文字图标 |
| `iconWidth` | `NodeStyleValue<number>` | 解析后 `size` 的 `0.6` 倍 | 仅图片图标，图坐标宽度 |
| `iconHeight` | `NodeStyleValue<number>` | 解析后 `size` 的 `0.6` 倍 | 仅图片图标，图坐标高度 |
| `iconFontFamily` | `NodeStyleValue<string>` | 系统无衬线字体栈 | 仅文字图标，所用字体须由应用加载 |
| `iconFontSize` | `NodeStyleValue<number>` | 解析后 `size` 的 `0.6` 倍 | 仅文字图标，图坐标字号；渲染后不足 4 个 Canvas 像素时跳过 |
| `iconColor` | `NodeStyleValue<string>` | `'#fff'` | 仅文字图标 |
| `iconOffsetX` | `NodeStyleValue<number>` | `0` | 图坐标偏移，正值向右 |
| `iconOffsetY` | `NodeStyleValue<number>` | `0` | 图坐标偏移，正值向下 |

图标尺寸和偏移随相机缩放，不使用 `label.scaleWithZoom` 的文字缩放策略。图标不参加标签碰撞隐藏，也不受 `nodeMinZoom` 控制；`hidden` 节点仍会跳过绘制。图片异步加载，成功后重绘；跨域图片需允许匿名 CORS，失败后本实例不会自动重试同一 URL。

```ts
import type { NodeConfig } from '@antv/g6-lite';

const node: NodeConfig = {
  style: {
    size: 40,
    label: (item) => String(item.data?.name ?? item.id),
    labelPlacement: 'bottom',
    labelMaxWidth: 120,
    labelBackground: '#fff',
    labelFontWeight: '600',
    icon: 'G',
    iconType: 'text',
    iconFontSize: 20,
    iconColor: '#fff',
  },
};
```

完整操作与效果见[标签与图标指南](/docs/guides/label)和[标签位置与图标示例](/docs/examples/labels)。

## NodeDecorationConfig

配置位置为 `node.decorations[]`，与 `style` 同级。装饰和图标是独立能力：一个节点可以同时有图标、文本标签和多个装饰。`renderer` 是每个装饰的必填项，其余字段均可省略。

### 内容与显示

| 字段 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `renderer` | `string` | 必填 | 已注册的 decoration 名称；`builtin-badge` 随库注册，无需再次注册 |
| `data` | `T \| ((node: GraphNode) => T)` | `undefined` | 单项模式下传给渲染器的数据；业务渲染器自行约定 `T` |
| `layout` | `'single' \| 'stack'` | 单项模式 | `'stack'` 使用 `items`，单项模式使用 `data` |
| `items` | `T[] \| ((node: GraphNode) => T[])` | `[]` | 仅 stack 模式，按项测量后组成纵向栈；空数组不绘制 |
| `minZoom` | `number` | `0` | 低于此相机缩放时跳过，数值与 `graph.getZoom()` 同一口径；负数或非有限值回退 `0` |
| `hideOnCollision` | `boolean` | `true` | 装饰组与先绘制的其他节点装饰碰撞时隐藏；`false` 允许重叠且不占用装饰碰撞网格 |

装饰使用独立于文字标签的碰撞网格，不会因碰撞策略抑制本节点标签；同一节点的多个装饰可以重叠。Graph 顶层 `label.nodeMinZoom`、`label.hideOnCollision` 等文字策略不控制装饰，装饰使用自己的显示选项。`hidden` 节点跳过装饰绘制。

### 放置与偏移

| 字段 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `placement` | `NodeStyleValue<NodeDecorationPlacement>` | `'top'` | `'center'`、`'top'`、`'bottom'`、`'left'`、`'right'` 或 `'follow-label'` |
| `attachment` | `'boundary' \| 'outside' \| 'inside'` | `'boundary'` | 沿节点轮廓、完整放在外侧或内侧；`placement: 'center'` 时放在节点中心 |
| `anchor` | `'start' \| 'center' \| 'end'` | `'center'` | 选择装饰盒沿放置方向的起点、中点或终点对齐，不是文字对齐方式 |
| `crossOffsetRatio` | `NodeStyleValue<number>` | `0` | 沿节点侧边的垂直方向偏移比例：左右侧按节点高度，上下侧按节点宽度；边界计算会限制到实际轮廓 |
| `boundaryOverlap` | `NodeStyleValue<number \| 'half-badge'>` | `0` | `anchor: 'start'` 时向节点侧重叠；数值为 CSS 像素，`'half-badge'` 取临近边界项高度的一半 |
| `offsetX` | `number` | `0` | 锚点计算后的水平偏移，CSS 像素，正值向右，不额外跟随相机缩放 |
| `offsetY` | `number` | `0` | 锚点计算后的垂直偏移，CSS 像素，正值向下，不额外跟随相机缩放 |

`'follow-label'` 当前仅在标签位置为 `'left'` 时选择左侧，其余标签位置均选择右侧，并非直接复制标签位置。`'half-badge'` 在顶部 stack 使用最后一项，其余方向使用第一项。内置 circle、rect 按实际轮廓计算边界；自定义节点可提供 `getBoundaryAnchor()`。

### 堆叠与溢出

| 字段 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `sort` | `'none' \| 'width-desc'` | 保持输入顺序 | 宽度降序排序；相同宽度保留原顺序 |
| `itemGap` | `number` | `2` | stack 项之间的纵向间距，CSS 像素 |
| `maxVisible` | `number` | 全部显示 | 使用正整数；发生折叠时，该上限包含为溢出项预留的位置 |
| `overflow` | `'clip' \| 'hover-expand'` | 折叠截断 | `'hover-expand'` 在鼠标进入溢出项区域后展开，离开展开区域后折叠 |
| `overflowData` | `T \| ((hiddenCount: number, node: GraphNode) => T)` | 无占位项 | 传给同一个渲染器的溢出项数据；引擎不会自动生成省略号 |

当有 4 项、`maxVisible: 3` 且未展开时，保留 2 项并预留一个溢出位置，`hiddenCount` 为 `2`。提供 `overflowData` 后会绘制第 3 个占位项；未提供时仍预留该位置，只显示前 2 项。`overflow: 'hover-expand'` 应搭配可见的 `overflowData`，以提供可悬停的展开入口。

stack 沿纵向排列，左侧装饰靠右对齐，其余放置方向靠左对齐。碰撞检测使用整个装饰组的测量框。

### 内置徽章

`builtin-badge` 消费 `NodeBadgeItem`。字段如下：

| 字段 | 类型 | 默认或用途 |
| --- | --- | --- |
| `kind` | `'count' \| 'lock' \| 'warning' \| 'favorite' \| 'text' \| 'icon'` | 必填，决定内容与默认配色 |
| `value` | `number \| string` | count 的数字或字符串，缺省为空文本 |
| `text` | `string` | text 的内容，缺省为空文本 |
| `icon` | `string` | icon 的文字或字体图标字符，缺省为空文本；这里不是图片 URL |
| `iconFontFamily` | `string` | icon 使用的字体族，默认 `'sans-serif'`，应用负责加载字体 |
| `fill` | `string` | 覆盖徽章背景色；默认 count、warning、text 为 `'#F4664A'`，lock、icon 为 `'#7E92B5'`，favorite 为 `'#FFBE3A'` |
| `color` | `string` | 覆盖前景色，默认 `'#FFFFFF'` |

圆形徽章直径为渲染后节点宽高中较小值的 `1/3`。text 徽章高度相同，最大宽度为该较小值的 `1.5` 倍，超长文字省略；icon 字符尺寸为徽章直径的 `2/3`。

```ts
import type { NodeBadgeItem, NodeConfig } from '@antv/g6-lite';

const badges = [
  { kind: 'count', value: 12 },
  { kind: 'warning' },
  { kind: 'text', text: '优先' },
  { kind: 'lock' },
] satisfies NodeBadgeItem[];

const node: NodeConfig = {
  style: { size: 56, label: (item) => item.id, labelPlacement: 'bottom' },
  decorations: [{
    renderer: 'builtin-badge',
    placement: 'right',
    attachment: 'boundary',
    anchor: 'start',
    boundaryOverlap: 'half-badge',
    layout: 'stack',
    items: badges,
    maxVisible: 3,
    overflow: 'hover-expand',
    overflowData: { kind: 'text', text: '···' } satisfies NodeBadgeItem,
  }],
};
```

可在[节点徽章示例](/docs/examples/decoration-badges)中验证内置徽章。`data`、`items`、`placement`、`crossOffsetRatio`、`boundaryOverlap` 支持节点回调，`overflowData` 额外接收隐藏数量；`offsetX`、`offsetY`、`itemGap` 等不支持函数。

### 自定义装饰渲染器

通过 `register('decoration', name, renderer)` 注册。`measure()` 接收 `ctx`、`node`、当前 `data`、`dpr`、`zoom`、`nodeWidth`、`nodeHeight`，返回 `{ width, height, data? }`；宽高必须是有限正数，单位为 Canvas 像素。节点宽高已经换算到渲染像素。`draw()` 还收到该次测量的 `layout`，其中 `layout.data` 可存放测量阶段的结果。

引擎负责定位、组布局、碰撞和视口裁剪；绘制上下文已平移到当前项中心。未注册的装饰、非法测量和测量或绘制异常会警告并跳过，不回退到标签渲染器，也不会阻断节点文字标签。完整用法见[Decoration Renderer](/docs/guides/extensions#decoration-renderer)。

## 状态样式

`NodeStateStyleOverride` 支持以下固定值，不支持逐字段函数：

| 字段 | 类型 | 作用 |
| --- | --- | --- |
| `fill` | `string` | 覆盖填充色 |
| `stroke` | `string` | 覆盖描边色 |
| `strokeWidth` | `number` | 覆盖描边宽度，图坐标长度 |
| `opacity` | `number` | 覆盖不透明度 |
| `haloWidth` | `number` | 节点外侧光晕宽度，图坐标长度 |

对每个已激活状态，引擎选择 `node.stateStyles[状态]`，未定义时再取扩展、主题中的同名状态对象。该选择以整个状态对象为单位，不会逐字段补齐主题同名状态；自定义状态样式需要写全希望保留的效果。多个状态按当前状态集合的迭代顺序覆盖，后处理的同名字段优先，`default` 不参与覆盖。

`hidden` 状态使基础外观透明并跳过其他状态外观计算。内置状态还对光晕有最低效果：`active` 的光晕为 `0` 时补为 `8`，`selected` 小于 `12` 时补为 `12`。因此仅在选中样式中设置 `haloWidth: 0` 不会移除选中光晕。

## 运行时更新

首次 `await graph.render()` 完成后，使用 `graph.updateOptions({ node: ... })` 更新。顶层字段浅合并；两侧都是 style 对象时按样式字段合并，涉及 style 函数时提供的新函数或对象替换旧 style。`stateStyles` 和 `decorations` 是顶层字段，更新时分别替换整个状态映射和装饰数组，不会按状态名或数组项逐项合并。

更新不重新执行布局，详见 [`updateOptions()`](/docs/api/graph#updateoptions)。
