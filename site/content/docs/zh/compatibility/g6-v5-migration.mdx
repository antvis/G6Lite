title: 从 G6 v5 迁移
description: 逐项迁移配置、数据、交互、事件和扩展，保留可回退的业务基线
---

核对范围：G6 5.1.1 的[官方接入方式](https://g6.antv.antgroup.com/en/manual/getting-started/quick-start)与当前 G6Lite 源码。G6Lite 不是 G6 的兼容构建；发布包与源码差异先看[稳定性](/docs/compatibility/api-stability)。

## 先判断是否应该迁移

先验证最复杂的节点、交互、标签和分组。强依赖任意 DOM/React 节点、多渲染器、SSR 出图、完整动画、图算法或成熟插件集合时，先保留 G6；逐项查看[能力比较](/docs/compatibility/library-comparison)，不要只比较包大小。

## 安装与导入

```bash
npm install @antv/g6-lite@0.1.0-beta.27
```

所有值和类型都从 @antv/g6-lite 包根导入；不迁入 src / dist 深层路径。

## 最小配置对照

G6 v5 通常使用容器 ID、labelText 与 drag-element；见[官方示例](https://g6.antv.antgroup.com/en/manual/getting-started/quick-start)。下列是独立的 G6Lite 起点，容器需先挂载且有非零尺寸：

```ts
import { Graph } from '@antv/g6-lite';

export async function mountGraph(container: HTMLElement) {
  const graph = new Graph({
    container,
    data: {
      nodes: [{ id: 'a' }, { id: 'b' }],
      edges: [{ id: 'a-b', source: 'a', target: 'b' }],
    },
    node: { style: { label: (node) => node.id } },
    layout: { type: 'circular', radius: 100 },
    behaviors: ['zoom-canvas', 'drag-canvas', 'drag-node', 'click-select'],
  });
  try {
    await graph.render();
    graph.fitView({ padding: 32, maxZoom: 1 });
    return () => graph.destroy();
  } catch (error) {
    graph.destroy();
    throw error;
  }
}
```

调用返回的函数清理实例；React/Vue 的异步卸载采用[框架示例](/docs/getting-started/react)，不要复制一个长期悬空的异步挂载任务。

## GraphOptions 对照

| G6 v5 | G6Lite |
| --- | --- |
| container ID | CSS 选择器 #container，或 HTMLElement |
| node.style.labelText | node.style.label |
| width / height | 容器 CSS；运行时 setSize |
| palette / renderer / animation | 不是同名兼容配置；按样式映射或保留 G6 |
| setOptions | updateOptions 仅 node / edge / label / theme；布局另行设置 |
| plugins / transforms / behaviors | 重新核对注册、名称、选项与生命周期 |

完整字段统一查[GraphOptions](/docs/api/options)。

## 数据字段映射

显式传 nodes、edges 数组，节点 id 唯一，端点引用已有节点；为边保留稳定 ID。坐标使用节点 x/y，归属使用 comboId，业务字段放 data。不要复制 G6 内部模型或依赖节点 style 原样兼容。

运行时新增节点需要坐标；全量替换与增量写入语义不同。见[输入数据](/docs/api/options/data) · [数据更新](/docs/guides/data)。

## Node、Edge 与 Combo 配置

内置 circle / rect 和常用边复用 WebGL 基型；任意场景图形状不是直接替代。状态样式分别位于 node.stateStyles、edge.stateStyles 与 combo.style.stateStyles。Combo 嵌套、折叠与运行时归组仍为实验能力。

[节点](/docs/api/options/node) · [边](/docs/api/options/edge) · [Combo](/docs/api/options/combo)

## Behavior 映射

| G6 v5 | G6Lite |
| --- | --- |
| drag-element | drag-node |
| hover-activate | hover-highlight 或对应状态 API |
| collapse-expand | collapseCombo / expandCombo / toggleCombo |
| create-edge | 业务创建后 addEdge；drag-edge 只重连已有边 |
| focus-element | focusItem |
| zoom-canvas / click-select | 名称可相同，仍需核对选项、载荷与组合键 |

省略 behaviors 使用默认缩放和平移；[] 关闭默认。逐项查[Behavior](/docs/api/options/behaviors)。

## Layout 迁移

同名算法不保证参数相同。迁移 center、rankdir、迭代与距离参数时，固定数据和节点尺寸；运行时用 setLayout 后 await layout。支持情况、取消和 Worker 查[布局参考](/docs/api/graph/layout)。

## 事件迁移

不导出 G6 的事件枚举，使用字符串事件名与 GraphEventMap。元素原生事件用 nativeEvent；选择、拖拽等派生载荷按各自契约读取，不全局替换 event 字段。监听需要配对 off。

[完整事件契约](/docs/api/graph/events) · [业务联动](/docs/guides/events)

## Graph API 映射

| G6 v5 | G6Lite 查询位置 |
| --- | --- |
| getNodeData(id?) / getEdgeData(id?) | 单个与列表分为 getNodeData / getNodes、getEdgeData / getEdges |
| addNodeData / removeNodeData | addNode(s) / removeNode(s) |
| setElementState / getElementState | setElementStates / getItemStates |
| hideElement / showElement | hideItem / showItem |
| focusElement / resize | focusItem / setSize |
| draw / render | render 与 refresh 语义不同，查生命周期 |

完整参数、返回值和缺失 ID 行为统一查[方法索引](/docs/api/graph)。新代码不使用 toData、isDestroyed 或内部 getCanvas/updateData。

## Extension、Transform 与 Plugin

G6 基类不能原样迁移。先选择扩展类别，再按[扩展教程](/docs/guides/extensions)与[公开契约](/docs/api/extensions)实现。受控上下文不提供完整 Graph；插件订阅可由宿主显式注入，并在 destroy 中清理。

## 当前不支持与替代方式

图算法可由独立分析链路计算后写回数据；外围工具可由业务 UI 或 Plugin 实现。无法收敛到支持图元、环境或生命周期的页面继续使用 G6，不把部分迁移写成完整兼容。

## 迁移验收清单

1. 锁定两个版本并保留原实现回退。
2. 验证数据、样式、标签、状态、分组及关键手势。
3. 覆盖更新、事件退订、异步卸载和重复挂载。
4. 按相同视觉与环境测量布局、渲染、交互与资源，再决定切换。
