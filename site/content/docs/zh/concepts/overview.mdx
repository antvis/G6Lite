---
title: G6Lite 是什么
description: 面向浏览器关系探索的图引擎：用途、使用模型和能力边界
---

G6Lite 是浏览器中的图可视化引擎。用节点和边表达关系，通过布局、缩放、拖拽、选择和高亮完成探索。节点与边使用 WebGL，标签和 Combo 使用 Canvas 2D。

## 适合的场景

- 关系探索、资产拓扑、知识图谱和依赖分析。
- 需要频繁选择、高亮、查询邻居和增量更新的分析界面。
- 常用点线图形和受控扩展能满足业务表达的产品。

数据规模不是单独的选型门槛：布局、标签密度、交互、DPR 和设备都会影响结果。用[性能测量入口](/docs/metrics/performance)验证真实工作负载。

## 需要评估的场景

任意 HTML / React 节点树、多渲染器、完整动画编排、成熟内置插件生态、图论算法或服务端出图，均不属于当前 G6Lite 的完整能力面。[Combo 的嵌套与折叠](/docs/api/options/combo)仍为实验能力。

渲染需要真实 DOM、Canvas 和 WebGL；SSR 框架应在客户端挂载后创建图。[运行环境](/docs/compatibility/browser)列出工程限制，[API 稳定性](/docs/compatibility/api-stability)说明实验及兼容边界。

## 与 G6 v5 的关系

G6Lite 与 G6 v5 使用不同的包和实现。相似的概念不代表配置、插件、事件或扩展协议可以直接互换。需要更广的图形、动画和插件能力时，比较 [G6 v5 等候选方案](/docs/compatibility/library-comparison)；迁移现有项目时逐项对照[迁移指南](/docs/compatibility/g6-v5-migration)。

## 使用模型

一个 `Graph` 管理一张图：`data` 描述关系，`node / edge` 定义外观，`layout` 计算位置，`behaviors` 处理交互，`theme` 统一样式。

先准备[有效数据](/docs/concepts/data-model)和有尺寸的容器，再 `new Graph(options)`、`await graph.render()`。运行时更新复用实例，离开页面时 `destroy()`。步骤见[快速上手](/docs/getting-started/quick-start)，时序见[生命周期](/docs/concepts/graph-lifecycle)，字段查[GraphOptions](/docs/api/options)。
