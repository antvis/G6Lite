选择一种接入方式。两种方式都用 6 个节点和 7 条边创建同一张团队协作图。

- [包管理器](#包管理器)适合使用 Vite、Webpack 等构建工具的项目。安装后从 `@antv/g6-lite` 导入 `Graph`。
- [CDN](#cdn)适合直接在 HTML 中使用。通过 `<script type="module">` 导入 `Graph`。

## 包管理器

### 安装

在使用 Vite、Webpack 等构建工具的项目中，选择一种包管理器安装：

<div className="quick-start-install">

```bash
# npm
npm install @antv/g6-lite@0.1.0
```

```bash
# pnpm
pnpm add @antv/g6-lite@0.1.0
```

```bash
# Yarn
yarn add @antv/g6-lite@0.1.0
```

</div>

### 创建关系图

安装后，在页面中添加一个有明确宽高的容器：

```html
<div id="container" style="width: 100%; height: 360px"></div>
```

然后在 JavaScript 或 TypeScript 入口中创建关系图。容器需要先挂载到页面，`await` 应在 ES 模块或 `async` 函数中使用。

```ts
import { Graph } from '@antv/g6-lite';

const data = {
  nodes: [
    { id: 'Alice', data: { color: '#5B8FF9', size: 40 } },
    { id: 'Bob', data: { color: '#5B8FF9', size: 28 } },
    { id: 'Carol', data: { color: '#5B8FF9', size: 28 } },
    { id: 'David', data: { color: '#61DDAA', size: 40 } },
    { id: 'Eva', data: { color: '#61DDAA', size: 28 } },
    { id: 'Frank', data: { color: '#61DDAA', size: 28 } },
  ],
  edges: [
    { source: 'Alice', target: 'Bob' },
    { source: 'Alice', target: 'Carol' },
    { source: 'David', target: 'Eva' },
    { source: 'David', target: 'Frank' },
    { source: 'Alice', target: 'David' },
    { source: 'Bob', target: 'Eva' },
    { source: 'Carol', target: 'Frank' },
  ],
};

const graph = new Graph({
  container: '#container',
  data,
  node: {
    style: {
      size: (node) => Number(node.data?.size ?? 26),
      fill: (node) => String(node.data?.color ?? '#5B8FF9'),
      stroke: '#fff',
      strokeWidth: 2,
      label: (node) => node.id,
      labelPlacement: 'bottom',
      labelColor: '#334155',
    },
  },
  edge: { style: { stroke: '#CBD5E1', lineWidth: 1.5 } },
  layout: {
    type: 'd3-force',
    linkDistance: 100,
    nodeStrength: -400,
    collideRadius: 32,
  },
  behaviors: ['zoom-canvas', 'drag-canvas', 'drag-node', 'hover-highlight'],
});

try {
  await graph.render();
  graph.fitView({ padding: 48, maxZoom: 1.2 });
} catch (error) {
  graph.destroy();
  throw error;
}
```

包中已包含 TypeScript 类型。

移除容器或卸载组件前，调用 `graph.destroy()` 释放资源。

## CDN

```js
import { Graph } from 'https://esm.sh/@antv/g6-lite@0.1.0?bundle';
```

### 创建关系图

将下面的 HTML 保存为 `index.html`，用浏览器打开。

```html
<!doctype html>
<html lang="zh-CN">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1" />
    <title>G6Lite 团队协作关系图</title>
  </head>
  <body>
    <div id="container" style="height: 360px"></div>
    <script type="module">
      import { Graph } from 'https://esm.sh/@antv/g6-lite@0.1.0?bundle';

      const data = {
        nodes: [
          { id: 'Alice', data: { color: '#5B8FF9', size: 40 } },
          { id: 'Bob', data: { color: '#5B8FF9', size: 28 } },
          { id: 'Carol', data: { color: '#5B8FF9', size: 28 } },
          { id: 'David', data: { color: '#61DDAA', size: 40 } },
          { id: 'Eva', data: { color: '#61DDAA', size: 28 } },
          { id: 'Frank', data: { color: '#61DDAA', size: 28 } },
        ],
        edges: [
          { source: 'Alice', target: 'Bob' },
          { source: 'Alice', target: 'Carol' },
          { source: 'David', target: 'Eva' },
          { source: 'David', target: 'Frank' },
          { source: 'Alice', target: 'David' },
          { source: 'Bob', target: 'Eva' },
          { source: 'Carol', target: 'Frank' },
        ],
      };

      const graph = new Graph({
        container: '#container',
        data,
        node: {
          style: {
            size: (node) => Number(node.data?.size ?? 26),
            fill: (node) => String(node.data?.color ?? '#5B8FF9'),
            stroke: '#fff',
            strokeWidth: 2,
            label: (node) => node.id,
            labelPlacement: 'bottom',
            labelColor: '#334155',
          },
        },
        edge: { style: { stroke: '#CBD5E1', lineWidth: 1.5 } },
        layout: {
          type: 'd3-force',
          linkDistance: 100,
          nodeStrength: -400,
          collideRadius: 32,
        },
        behaviors: ['zoom-canvas', 'drag-canvas', 'drag-node', 'hover-highlight'],
      });

      graph.render().then(() => {
        graph.fitView({ padding: 48, maxZoom: 1.2 });
      }).catch((error) => {
        graph.destroy();
        console.error(error);
      });
      window.addEventListener('pagehide', () => graph.destroy(), { once: true });
    </script>
  </body>
</html>
```

单页示例在 `pagehide` 时销毁图实例。浏览器从往返缓存恢复页面时，需要重新创建实例。
