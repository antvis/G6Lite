## 包管理器

在使用 Vite、Webpack 等构建工具的项目中，选择一种包管理器安装：

<div className="quick-start-install">

```bash
# npm
npm install @antv/g6-lite
```

```bash
# pnpm
pnpm add @antv/g6-lite
```

```bash
# Yarn
yarn add @antv/g6-lite
```

</div>

安装后，在页面中添加一个有明确宽高的容器：

```html
<div id="container" style="width: 100%; height: 360px"></div>
```

然后在 JavaScript 或 TypeScript 入口中创建关系图。容器需要先挂载到页面，`await` 应在 ES 模块或 `async` 函数中使用。

```ts
import { Graph } from '@antv/g6-lite';

const data = {
  nodes: [
    { id: 'Alice', data: { color: '#5B8FF9', size: 40 } },
    { id: 'Bob', data: { color: '#5B8FF9', size: 28 } },
    { id: 'Carol', data: { color: '#5B8FF9', size: 28 } },
    { id: 'David', data: { color: '#61DDAA', size: 40 } },
    { id: 'Eva', data: { color: '#61DDAA', size: 28 } },
    { id: 'Frank', data: { color: '#61DDAA', size: 28 } },
  ],
  edges: [
    { source: 'Alice', target: 'Bob' },
    { source: 'Alice', target: 'Carol' },
    { source: 'David', target: 'Eva' },
    { source: 'David', target: 'Frank' },
    { source: 'Alice', target: 'David' },
    { source: 'Bob', target: 'Eva' },
    { source: 'Carol', target: 'Frank' },
  ],
};

const graph = new Graph({
  container: '#container',
  data,
  node: {
    style: {
      size: (node) => Number(node.data?.size ?? 26),
      fill: (node) => String(node.data?.color ?? '#5B8FF9'),
      stroke: '#fff',
      strokeWidth: 2,
      label: (node) => node.id,
      labelPlacement: 'bottom',
      labelColor: '#334155',
    },
  },
  edge: { style: { stroke: '#CBD5E1', lineWidth: 1.5 } },
  layout: {
    type: 'd3-force',
    linkDistance: 100,
    nodeStrength: -400,
    collideRadius: 32,
  },
  autoFit: { padding: 48, maxZoom: 1.2 },
  behaviors: ['zoom-canvas', 'drag-canvas', 'drag-node', 'hover-highlight'],
});

try {
  await graph.render();
} catch (error) {
  graph.destroy();
  throw error;
}
```

示例使用力导向布局自动排列节点，并通过节点数据映射颜色和大小。`behaviors` 启用缩放、平移、节点拖拽和悬停高亮。包中已包含 TypeScript 类型。

## CDN

UMD 构建通过 `window.G6Lite` 暴露公开 API，可以直接在 HTML 中使用 `new G6Lite.Graph()`。

下面是完整的 HTML 示例。UMD 文件已包含运行时依赖和布局算法，无需再加载其他脚本：

<details>

```html
<!doctype html>
<html lang="zh-CN">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1" />
    <title>G6Lite 团队协作关系图</title>
  </head>
  <body>
    <div id="container" style="height: 360px"></div>
    <script src="https://cdn.jsdelivr.net/npm/@antv/g6-lite@beta/dist/g6-lite.min.js"></script>
    <script>
      const data = {
        nodes: [
          { id: 'Alice', data: { color: '#5B8FF9', size: 40 } },
          { id: 'Bob', data: { color: '#5B8FF9', size: 28 } },
          { id: 'Carol', data: { color: '#5B8FF9', size: 28 } },
          { id: 'David', data: { color: '#61DDAA', size: 40 } },

          { source: 'Alice', target: 'David' },

        ],
      };

      const graph = new G6Lite.Graph({
        container: '#container',
        data,
        node: {
          style: {
            size: (node) => Number(node.data?.size ?? 26),
            fill: (node) => String(node.data?.color ?? '#5B8FF9'),
            stroke: '#fff',
            strokeWidth: 2,
            label: (node) => node.id,
            labelPlacement: 'bottom',
            labelColor: '#334155',
          },
        },

        layout: {
          type: 'd3-force',

          collideRadius: 32,

        graph.destroy();
        console.error(error);
      });
      window.addEventListener('pagehide', () => graph.destroy(), { once: true });
    </script>
  </body>
</html>
```

</details>

生产环境使用 CDN 时，应锁定包含 UMD 文件的确切版本号。ESM 入口按需加载布局，UMD 则包含布局算法，两者的下载体积不同，详见[包体积](/docs/metrics/bundle-size)。

## 验证效果与清理

看到 6 个带标签的节点和 7 条边后，尝试滚轮缩放、空白处平移、拖拽节点和悬停高亮。图没有显示时，先检查容器非零宽高、浏览器 WebGL 和控制台错误，见[常见问题](/docs/faq)。

包管理器示例在真实 DOM 挂载后运行；组件卸载或移除容器前，调用：

```ts
graph.destroy();
```

不要只删除 DOM 后继续持有实例。CDN 单页示例通过 pagehide 清理；若页面从浏览器往返缓存恢复，需要重新创建图。应用路由中的挂载与清理使用下方框架方案。

## 在前端框架中使用

在 React / Vue 中，通过 ref 获取真实 DOM，在客户端挂载后创建实例，并在组件卸载时调用 `graph.destroy()` 释放资源。
