## 选择方式

| 操作 | 配置 |
| --- | --- |
| 点击节点或边切换选中 | `click-select`。开启 `multiple` 后，按住 `trigger` 指定的键可追加选择 |
| 用矩形框选节点 | `brush-select`，用 `key` 设置启动手势 |
| 沿自由轮廓圈选节点 | `lasso-select`，用 `key` 设置启动手势 |
