悬停或点击节点和边时，显示它们的详细信息。

## 配置方式

触发方式通过 `trigger` 设置，内容通过 `getContent` 返回。点击触发时，再次点击同一元素或点击空白处可关闭提示框。

```ts
behaviors: [{ type: 'tooltip', trigger: 'hover', delay: 120 }],
```
