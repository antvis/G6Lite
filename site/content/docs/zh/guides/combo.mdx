Combo 用包围框组织节点。按需从[声明分组](#声明-combo)、[折叠展开](#折叠与展开)或[动态归组](#动态调整归属)开始；完整字段见 [Combo 配置参考](/docs/api/options/combo)。嵌套、折叠和运行时归组属于[实验性能力](/docs/compatibility/api-stability#实验性能力)。

## 声明 Combo

1. 在 `data.combos` 中声明唯一 id，节点用 `comboId` 加入分组。
2. 需要嵌套时，在子 Combo 上写 `parentId`；边仍连接节点 id。
3. 提供节点坐标或布局，再调用 `await graph.render()`。边界随成员位置和 padding 计算。

## ComboData

数据中用 `collapsed`、`states` 声明初始状态，业务字段放 `data`。完整类型与归属规则见 [ComboData 参考](/docs/api/options/combo#combodata)。

## 样式

在上例的 `combo.style` 中配置公共外观，单组用 `data.combos[].style` 覆盖。

- 标题：显式配置 `label`，例如回调读取 data.name；业务名称不会自动显示。
- 边界：用 padding 留白、fill/stroke 区分类别。padding 数组当前取最大值应用四周。
- 选中：在 `combo.style.stateStyles.selected` 中定义效果，再用状态 API 激活；内置 click-select 不会自动选择 Combo。

```ts
graph.setItemState('client', 'selected', true);
graph.setItemState('client', 'selected', false);
```

需要对照效果时看[全局与局部外观](/docs/api/options/combo#代码与对应效果)和[状态样式示例](/docs/api/options/combo#状态样式)。

## 折叠与展开

首次折叠用 `ComboData.collapsed: true`；首次 render 后使用以下方法。折叠隐藏后代节点与关联边，当前不生成连接到折叠分组的虚拟边。

```ts
graph.on('combo:collapse', ({ comboId }) => console.log('Collapsed:', comboId));
graph.on('combo:expand', ({ comboId }) => console.log('Expanded:', comboId));
graph.collapseCombo('client');
graph.expandCombo('client');
graph.toggleCombo('client');
```

下面点击分组可展开、折叠。圆形显示自动计数，矩形分别显示自定义计数和标签；尺寸与文字优先级见[折叠形态参考](/docs/api/options/combo#折叠形态)。

## 动态调整归属

首次 render 后，`addToCombo(nodeId, comboId)` 将已有节点转入已有分组，包围框随渲染更新。它不自动搬动节点或重新布局。

```ts
graph.removeFromCombo('mobile');

graph.removeCombo('temporary');
graph.addToCombo('mobile', 'client');
```

这些方法更新已有实例，不需要重新 render。更多签名见 [Combo 方法](/docs/api/graph/combo)。

## 查询

用查询确认归属和折叠状态，返回的模型只读；`getComboChildren()` 只返回直接成员。

```ts
const membership = graph.getNodeCombo('mobile'); // 'client' 或 'service'
const children = graph.getComboChildren('client'); // { nodes, combos }
const collapsed = graph.getComboData('client')?.collapsed;
const snapshot = graph.getData(); // 当前归属与状态的数据快照
```

## 整体拖拽

上面的归组示例已启用 `drag-node`：拖动分组空白处会移动全部后代节点，拖动节点则移动该节点；空画布由 `drag-canvas` 平移。拖动越过分组边界不会自动改变归属。

需要同步业务状态时，监听 `combo:dragstart`、`combo:drag`、`combo:dragend`；结束后通过 `getData()` 读取位置。

## 常见问题

### 为什么分组没有边框或标题？

确认成员 comboId 有效、节点已有位置；空分组不绘制占位框。标题必须通过 label 显式提供。

### 为什么隐藏或折叠父组后仍有内容？

hidden 仅隐藏分组自身；折叠隐藏后代节点和关联边，但子 Combo 边框不随祖先折叠自动隐藏。嵌套折叠需核对实际效果，见[边界说明](/docs/api/options/combo#初始折叠)。

### 为什么展开后仍有节点看不到？

检查节点、边原有的 hidden，以及其他祖先是否仍折叠；展开会保留这些隐藏条件。

### 为什么拖动没有改变归属或选中状态？

drag-node 只移动位置。归属由 addToCombo/removeFromCombo 控制，选中由状态 API 控制；三者需分别处理。

### 为什么 updateOptions 不能改 Combo 外观？

当前不接受 combo。局部样式用数据快照配合 setData，全局样式重建实例，见[更新方式](/docs/api/options/combo#运行时修改边界)。
