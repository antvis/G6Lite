本页介绍数据接入与运行时更新。节点、边和 Combo 的关系见[数据模型](/docs/concepts/data-model)，完整字段见[配置参考](/docs/api/options#图数据)。

## 接入业务数据

将业务实体映射为节点，将实体之间的关系映射为边。业务字段放入 `data`，供样式函数、Tooltip 和业务逻辑读取：

```ts
import type { GraphData } from '@antv/g6-lite';

const users = [
  { id: 'alice', name: 'Alice', team: 'design' },
  { id: 'bob', name: 'Bob', team: 'engineering' },
];

const data: GraphData = {
  nodes: users.map((user) => ({
    id: user.id,
    data: { name: user.name, team: user.team },
  })),
  edges: [{ source: 'alice', target: 'bob' }],
};
```

将转换后的数据作为 `new Graph({ container, data })` 的 `data` 选项。首次创建与渲染的完整代码见[快速上手](/docs/getting-started/quick-start)。

## 校验数据

- 节点 `id` 在图内唯一，后续更新时保持稳定。
- 边的 `source` 和 `target` 必须对应已有节点。
- 使用 Combo 时，节点的 `comboId` 应对应已声明的分组。
- 未配置布局时，应提供节点的 `x` / `y`，避免所有节点落在缺省坐标。
- 修改图数据应通过公开方法完成，不要直接改写查询返回的 Model。

## 替换整份数据

以下操作都应在首次 `await graph.render()` 完成后执行。

筛选条件变化、切换数据集或请求返回完整结果时，使用 `setData()`：

```ts
await graph.setData(nextData);
```

配置了布局时会重新计算坐标；默认会重新适配视口。如果希望保留用户当前的缩放和平移：

```ts
await graph.setData(nextData, { fitView: false });
```

这里的 `fitView` 控制本次数据替换后的适配；容器尺寸变化后的适配由 [`autoFit`](/docs/api/options#autofit) 控制。

## 增量更新

只修改少量元素时，使用增删改方法：

```ts
graph.addNode({ id: 'carol', x: 120, y: 80, data: { name: 'Carol' } });
graph.addEdge({ source: 'alice', target: 'carol' });
graph.updateNodeData('carol', { name: 'Carol Chen' });
graph.removeNode('bob');
```

新增节点需要提供坐标，增量方法不会自动重新布局。需要重新排列时，按[布局指南](/docs/guides/layout#运行时重新布局)调用 `layout()`；更新多个元素时，可使用批量方法减少重复刷新。

选中、高亮、隐藏等变化使用[状态与显隐 API](/docs/api/graph#状态显隐和定位)，无需替换整份数据。
