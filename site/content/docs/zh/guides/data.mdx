## 接入业务数据

实体映射为节点、关系映射为边，业务字段放 data，交给样式、Tooltip 或业务面板读取。为需要跨刷新匹配的边也提供稳定 ID。

```ts
import type { GraphData } from '@antv/g6-lite';

const users = [
  { id: 'alice', name: 'Alice', team: 'design' },
  { id: 'bob', name: 'Bob', team: 'engineering' },
];

const data: GraphData = {
  nodes: users.map((user) => ({
    id: user.id,
    data: { name: user.name, team: user.team },
  })),
  edges: [{ source: 'alice', target: 'bob' }],
};
```

这段仅转换数据；首次展示还需容器和 render。未提供坐标时配置布局，完整初始化见[快速上手](/docs/getting-started/quick-start)。

## 校验数据

- 节点、边、Combo 使用稳定字符串 ID，避免跨类型重名。
- 边端点引用已存在节点，Combo 归属与父级须有效且无环。
- 无布局时提供有限 x/y；固定轴约束由应用保留，见字段参考。
- 先校验再写入，批量方法不保证事务回滚，不直接改 Model。

## 选择更新方式

| 变化 | 方法 | 保留或重算 |
| --- | --- | --- |
| 切换数据集 / 全量返回 | setData | 替换全图，有配置就布局；默认适配 |
| 少量业务字段变化 | updateNodeData / updateEdgeData | 浅合并 data，不重布局 |
| 新增或删除元素 | addNode(s) / addEdge(s) / remove… | 新增节点提供坐标，删除节点连带删除边 |
| 位置变化 | updateNodePosition(s) | 图坐标变化，不改变身份 |
| 选择、隐藏、归组 | 状态 / Combo 方法 | 按所属主题修改，不必全量替换 |

## 替换整份数据

首次有效 render 完成后调用 setData。默认重布局并 fitView(0.9)；传 fitView: false 保留相机。先缩放下面画布，再对比两种刷新，B 的坐标在 240 / 800 间切换。

## 增量更新

Update A 递增 score 并更新尺寸；Add D 创建节点和 C-D；Remove D 自动删除关联边。Edit snapshot 只改导出副本，不写回。

增量方法不重新布局或适配，常规更新不需要 render。多个元素优先批量方法；嵌套 data 是浅合并，不是递归合并。

<details>
<summary>异步请求：取消旧请求与卸载清理</summary>

下面的辅助函数拥有此页面 Graph 的清理职责。load 接受 AbortSignal；调用 refresh 时处理失败提示，退出时调用 dispose。

```ts
import type { Graph, GraphData } from '@antv/g6-lite';
export function createLoader(graph: Graph, load: (signal: AbortSignal) => Promise<GraphData>) {
  let version = 0;
  let disposed = false;
  let controller: AbortController | undefined;
  return {
    async refresh() {
      const request = ++version;
      controller?.abort();
      const current = new AbortController();
      controller = current;
      try {
        const next = await load(current.signal);
        if (disposed || graph.destroyed || request !== version) return;
        await graph.setData(next, { fitView: false });
      } catch (error) {
        if (!current.signal.aborted && !disposed) throw error;
      }
    },
    dispose() {
      disposed = true;
      version++;
      controller?.abort();
      graph.destroy();
    },
  };
}
```

## 常见问题

### 更新后标签或颜色没变？

确认字段写在 data，样式回调读取同名字段；修改导出副本或直接改 Model 不会按公开流程更新。

### 更新后为什么视野或选择丢了？

setData 默认适配，状态按新输入建立。保留相机用 fitView: false，保留选择则按稳定 ID 显式恢复。
