## 概述

节点按有向边的关系分层排列。

## 使用场景

适合流程图、调用链和依赖图。

## 基本用法

布局类型通过 `layout.type` 指定。

```ts
const graph = new Graph({
  container,
  data,
  layout: { type: 'dagre' },
});
```

## 配置项

| 参数 | 描述 | 类型 | 默认值 |
| --- | --- | --- | --- |
| `rankdir` | 分层方向。`'LR'` 从左到右，`'TB'` 从上到下。 | `'TB'` \| `'BT'` \| `'LR'` \| `'RL'` | `'TB'` |
| `nodesep` | 同一层中节点之间的间距。 | `number` | `50` |
| `ranksep` | 层与层之间的间距。 | `number` | `50` |
| `nodeSize` | 参与计算的节点宽高。 | `number` \| `[number, number]` | `[0, 0]` |
