节点通过 `node` 配置类型与样式。`circle` 与 `rect` 都由 WebGL program 绘制，适合大规模渲染。

## 基础配置

```ts
node: {
  type: 'circle',
  style: {
    size: 16,
    fill: '#1783FF',
  },
}
```

## 顶层配置

以下选项位于 `node` 下，与 `style` 同级：

| 选项 | 用途与支持状态 |
| --- | --- |
| `type` | 使用内置 `circle`、`rect` 或已注册的节点类型 |
| `style` | 配置基础外观、标签和图标；支持对象及样式函数 |
| `stateStyles` | 覆盖节点进入选中、高亮等状态时的基础外观 |
| `labelRenderer` | 使用已通过 `register('label', ...)` 注册的标签渲染器；仍需配置 `style.label` 提供文本 |
| `decorations` | 挂载徽章等节点装饰；可使用内置 `builtin-badge`，或注册自定义 decoration |
| `autoExternalLabelPlacement` | 当前仅有类型声明，运行时未读取该选项，设置后不会自动调整标签位置 |

需要固定标签位置时，显式设置 `node.style.labelPlacement`，例如 `'bottom'`。装饰用法见[扩展体系中的 Decoration Renderer](/docs/guides/extensions#decoration-renderer)，字段结构见[节点配置](/docs/api/options#节点)。

## 类型

| 类型     | 说明               | 常用尺寸字段       |
| -------- | ------------------ | ------------------ |
| `circle` | 圆形节点，默认类型 | `size`             |
| `rect`   | 矩形节点           | `width` / `height` |

## 样式字段

| 字段                     | 说明                                          |
| ------------------------ | --------------------------------------------- |
| `fill`                   | 填充色                                        |
| `size`                   | 圆形直径                                      |
| `width` / `height`       | 矩形尺寸                                      |
| `stroke` / `strokeWidth` | 描边颜色与宽度                                |
| `opacity`                | 不透明度                                      |
| `borderRadius`           | 矩形圆角                                      |
| `label*`                 | 标签字段，见 [标签与图标](/docs/guides/label) |
| `icon*`                  | 图标字段，见 [标签与图标](/docs/guides/label) |

大多数字段支持值或函数形式：

```ts
node: {
  style: {
    size: (node) => ((node.data?.value as number) ?? 1) * 4 + 12,
    fill: (node) => (node.data?.cluster === 'a' ? '#1783FF' : '#00C9C9'),
  },
}
```

函数式样式的实际效果——节点颜色和尺寸都来自数据字段（[查看完整示例](/docs/examples/node-style)）：

![节点颜色与尺寸由数据字段映射，同一组关系中可使用不同的节点样式。](/examples/docs-node-style.png '函数式节点样式')

## 状态样式

```ts
node: {
  stateStyles: {
    selected: { stroke: '#1890ff', strokeWidth: 3 },
    highlight: { stroke: '#faad14', strokeWidth: 3 },
    inactive: { opacity: 0.25 },
    hidden: { opacity: 0 },
  },
}
```

运行时切换状态：

```ts
graph.setItemState('node-a', 'selected', true);
graph.setItemState('node-b', 'inactive', true);
```

六种内置状态在节点和边上的实际表现见 [默认主题与交互状态](/docs/examples/default-theme) 示例。

## 性能建议

- 优先使用静态样式；函数式样式适合按数据分类，但不要在函数中做重计算。
- 大图中尽量减少全量标签，标签绘制由 Canvas 2D 承担。
- 高频交互优先切换状态，不要频繁重建整份数据。
