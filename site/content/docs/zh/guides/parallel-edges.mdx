---
title: 平行边与自环处理
description: 处理多条同源同目标边和自环边的展示
---

同一对节点之间存在多条边时，默认直线会重叠。可以启用 `process-parallel-edges` transform 让平行边自动错开。

处理前后与自环的效果示意：多条边从重叠变为可区分的路径，自环连接同一个节点。

![三条平行边处理前重叠、处理后错开及多个自环的示意](/examples/docs-guide-parallel-edges.svg '平行边与自环')

可运行示例：[平行边](/docs/examples/parallel-edges)、[自环](/docs/examples/edge-loops)。

```ts
const graph = new Graph({
  container: '#container',
  data,
  edge: {
    type: 'arc',
    style: {
      endArrow: true,
      lineWidth: 2,
    },
  },
  transforms: [
    {
      type: 'process-parallel-edges',
      options: { offset: 18 },
    },
  ],
});
```

`offset` 是平行边在图坐标中的偏移步长，默认 `20`。transform 的参数放在 `options` 中；例如，将 `offset` 从 `18` 改为 `36`，会增大同组平行边的间距。`distance` 不是这里的配置项。

也可以直接配置 `edge.parallelEdges`，无需再添加 transform：

```ts
edge: {
  type: 'arc',
  parallelEdges: { enabled: true, offset: 18 },
}
```

仅使用对象形式的 `edge.parallelEdges` 启用分离时，需要设置 `enabled: true`；使用默认参数可直接写 `parallelEdges: true`。两种入口选一种即可；同时配置时，`edge.parallelEdges` 对象中的字段覆盖 transform 的对应选项，显式设置 `parallelEdges: false` 或 `enabled: false` 会关闭分离。

自环边的 `source` 和 `target` 相同，由内置渲染器单独绘制，无需启用此 transform。`offset` 控制平行边分离，不控制自环大小。更新边时建议保留稳定的边 `id`。

## 使用建议

- 平行边较多时，优先使用 `arc` 或 `cubic`。
- 有方向语义时开启 `endArrow`。
- 标签较多时，避免所有平行边同时显示标签。
- 若业务侧有边分组语义，可以把分组信息放在 `edge.data` 中，用颜色或标签区分。
