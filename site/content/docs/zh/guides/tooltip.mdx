Tooltip 通过 behaviors 启用，只处理节点和边。需要缩放和平移时，将 zoom-canvas、drag-canvas 一并写入列表；仅写 tooltip 会替换默认导航。

## 自定义内容

悬停 API、DB 或边，等待 120ms 显示卡片；移开隐藏。Cache 节点被 enable 排除。代码返回 HTMLElement，用 textContent 展示业务值，因此 API 名称中的尖括号会作为普通文字显示。

## 点击显示

## 配置项

完整默认值、函数签名、container 和 TooltipContext 字段统一查 [TooltipOptions](/docs/api/options/behaviors#tooltipoptions) 与 [TooltipContext](/docs/api/options/behaviors#tooltipcontext)。ctx.event 是原始鼠标事件；它与普通 Graph 事件的 nativeEvent 命名不同。

默认内容是节点 data.label/id、边 data.label 或两端名称。自定义 getContent 返回字符串时按 HTML 写入，应自行转义动态内容；不需要 HTML 时，优先像上例一样返回填充 textContent 的元素。

## 样式

库只负责定位与显隐，不附带视觉皮肤。两个示例直接在返回元素上设置样式；也可给浮层 className 配置样式，例如默认类名：

```css
.g6lite-tooltip {
  padding: 8px 12px;
  border-radius: 8px;
  background: #163b65;
  color: white;
  font-size: 12px;
}
```

默认挂载 document.body，按视口定位并在边缘翻转。自定义 container 同时改变挂载与碰撞边界，需检查定位祖先、滚动和裁剪；不要假定祖先的 transform 不影响 fixed 定位。

## 常见问题

### 为什么卡片没有背景，或者点击不了？

库没有内置视觉皮肤，需要业务 CSS。浮层默认 pointer-events: none；需要按钮、表单或可交互卡片时，用应用自己的浮层承接。

### 为什么 Combo 上没有 Tooltip？

内置 tooltip 只处理 node/edge。Combo 说明可用公开事件结合业务浮层实现，不使用内部拾取接口。

### 更新数据后，已打开的内容会立即更新吗？

不会因 setData 自动重建 Tooltip；在后续指针事件中重新读取内容。切换配置需更换实例，销毁实例会解除监听、清理计时器并移除浮层。
