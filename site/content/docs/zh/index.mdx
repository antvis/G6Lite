## 核心能力

浏览器 WebGL 绘制节点与边，Canvas 2D 呈现标签与分组；支持布局、状态、增量更新和受控扩展。适用场景与边界统一见[产品介绍](/docs/concepts/overview)，实现原理见[技术架构](/docs/concepts/architecture)。
