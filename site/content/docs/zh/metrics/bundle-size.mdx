## ESM 与布局分块

包根 ESM 导入适合构建工具消费。布局按类型加载，首屏仍可能需要 regl、事件依赖和当前算法；不能把 index.js 大小当成页面总下载量。Worker 还需要正确部署对应资源。

[布局加载与 Worker](/docs/guides/layout-worker) · [运行环境](/docs/compatibility/browser)

## UMD / CDN

源码构建提供 UMD；已核对的 npm beta.27 发布包未包含该文件，不能仅凭 package.json 字段猜测 CDN URL。script 接入的完整步骤见[快速上手](/docs/getting-started/quick-start#cdn)。

## 如何复测

固定源码与依赖后构建，分别记录入口、分块、Worker 与整包。对每个文件用相同 gzip 等级压缩；再在业务页面 Network 中记录首次与缓存命中的实际资源请求。

package.json 中的 limit-size 是构建预算，不能证明当前 CI 已通过，也不能替代完整业务下载测量。跨库选型查[能力对比](/docs/compatibility/library-comparison)，运行速度查[性能测量](/docs/metrics/performance)。
