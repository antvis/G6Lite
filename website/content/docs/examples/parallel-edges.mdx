这个示例展示 `process-parallel-edges` transform 和 `edge.parallelEdges` 配置。它会把同一对节点之间的多条边错开，避免互相覆盖。

</div>

## 代码

```ts
const graph = new Graph({
  container,
  data,
  transforms: ['process-parallel-edges'],
  edge: {
    parallelEdges: {
      enabled: true,
      offset: 26,
      includeReverse: true,
    },
    style: {
      endArrow: true,
      label: (_source, _target, edge) => String(edge.data?.label ?? ''),
      labelBackground: 'rgba(255,255,255,0.92)',
      labelAutoRotate: true,
    },
  },
  behaviors: ['zoom-canvas', 'drag-canvas', 'drag-node', 'hover-highlight', 'click-select'],
});

await graph.render();
```
