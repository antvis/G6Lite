title: 交互
description: 内置 behaviors —— 缩放、拖拽、高亮、选中,以及 Tooltip
---

`behaviors` 为字符串或配置对象数组（`{ type: 'drag-node', ... }`）,内置以下行为（均为 **kebab-case** 命名）：

不传 `behaviors` 时默认启用 `zoom-canvas` 和 `drag-canvas`。显式传入数组后以该数组为完整配置，`behaviors: []` 可关闭全部默认行为。节点拖拽 `drag-node` 不会默认开启。

| 行为                | 说明                                  |
| ------------------- | ------------------------------------- |
| **zoom-canvas**     | 滚轮缩放画布                          |
| **drag-canvas**     | 拖拽平移画布                          |
| **drag-node**       | 拖拽移动节点（支持 Combo 整体拖拽）   |
| **drag-edge**       | 拖拽边的端点                          |
| **click-select**    | 单击选中节点 / 边,发出 `selectchange` |
| **hover-highlight** | 悬停高亮（节点与边合一）              |
| **highlight-node**  | 悬停节点时高亮该节点及一度邻居        |
| **highlight-edge**  | 悬停边时高亮该边及两端节点            |
| **brush-select**    | 框选（矩形）                          |
| **lasso-select**    | 套索选择（自由多边形）                |
| **tooltip**         | 悬停 / 点击显示浮层提示（见下）       |

> **架构说明**：单击、双击、右键、滚轮、悬停等**元素事件**由内核统一的「交互调度层」(`InteractionDispatcher`) 唯一分发——它做一次命中检测（`node → edge → combo → canvas` 优先级）,在 `graph.eventEmitter` 上发出规范事件,所有 behavior 都是这些事件的**消费者**。因此旧的 `click-node` / `wheel` 行为已移除（事件改由调度层默认发出）,无需再显式启用。

可同时启用多个;当同时启用 `highlight-node` 与 `highlight-edge` 时,边悬停优先。交互产生的事件可通过 `graph.on(eventName, handler)` 监听（事件清单见 [API 参考](/docs/api)）。

```ts
behaviors: ['zoom-canvas', 'drag-canvas', 'drag-node', 'click-select'];

// 监听选中变化
graph.on('node:selectchange', ({ nodeId, selected }) => {
  console.log(nodeId, selected);
});
```

框选与套索均支持以修饰键激活,避免与 `drag-canvas` 冲突。例如让普通拖拽平移、Shift+拖拽框选：

```ts
behaviors: ['drag-canvas', { type: 'brush-select', key: 'shift' }];
```

`drag-canvas` 默认忽略 Shift、Ctrl 和 Meta 修饰键手势，将它们留给框选、套索等组合交互。如需让修饰键拖拽仍然平移，可配置 `{ type: 'drag-canvas', ignoreModifierKeys: false }`。

## Tooltip

`tooltip` 开箱即用——加入 `behaviors: ['tooltip']` 即可,命中事件由调度层默认发出,不依赖其它 behavior。

| 选项         | 类型                             | 默认值             | 说明                                                             |
| ------------ | -------------------------------- | ------------------ | ---------------------------------------------------------------- |
| `trigger`    | `'hover' \| 'click'`             | `'hover'`          | 触发方式                                                         |
| `getContent` | `(ctx) => string \| HTMLElement` | label / id         | 自定义内容;返回字符串走 `innerHTML`（转义自负）,返回元素直接挂载 |
| `enable`     | `(ctx) => boolean`               | 总是显示           | 按元素控制是否显示                                               |
| `offset`     | `[number, number]`               | `[10, 10]`         | 相对指针偏移                                                     |
| `delay`      | `number`                         | `80`               | hover 防抖（ms）                                                 |
| `className`  | `string`                         | `'g6lite-tooltip'` | 浮层 class                                                       |

`ctx`（`TooltipContext`）含 `itemType`（`'node' \| 'edge'`）、`nodeId` 或 `edgeIndex`/`source`/`target`、`data`、`event`。浮层是 `position:fixed; pointer-events:none` 的单例 div,挂在 `document.body` 上并在视口边缘翻转;**库本身不附带视觉样式**,由应用通过 `.g6lite-tooltip`（或自定义 `className`）提供。

```ts
behaviors: [
  {
    type: 'tooltip',
    trigger: 'hover',
    getContent: (ctx) =>
      ctx.itemType === 'node'
        ? `<b>${ctx.data?.label ?? ctx.nodeId}</b>`
        : `${ctx.source} → ${ctx.target}`,
  },
];
```
