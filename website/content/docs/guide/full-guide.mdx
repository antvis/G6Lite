## 快速开始

### 安装

```bash
npm install @antv/g6-lite
```

### 最简示例

```ts
import { Graph } from '@antv/g6-lite';

const graph = new Graph({
  container: 'container',  // 容器选择器或 DOM 元素
  data: {
    nodes: [
      { id: '0' },
      { id: '1' },
    ],
    edges: [{ source: '0', target: '1' }],
  },
  layout: { type: 'circular', radius: 150 },
  behaviors: ['zoom-canvas', 'drag-canvas'],
  theme: 'light',
});

await graph.render();
```

创建 `Graph` 后必须调用 `await graph.render()` 才会执行布局并绘制。销毁时调用 `graph.destroy()`。

## 数据格式

图数据通过 `data` 传入，结构为 `{ nodes, edges, combos? }`。

### nodes

- **id**（必填）：节点唯一标识。
- **name**（可选）：名称。
- **data**（可选）：扩展数据，可用于样式函数或业务逻辑。
- **x, y**（可选）：若不做布局或部分节点需固定位置时可传。
- **states**（可选）：初始状态数组，如 `['selected']`。
- **comboId**（可选）：所属 Combo 的 id，详见 [Combo](/docs/guide/combo)。

```ts
const nodes = [
  { id: '0', name: '节点0', data: { cluster: 'a', value: 1 } },
  { id: '1', name: '节点1', data: { cluster: 'b' } },
];
```

### edges

- **source**（必填）：起点节点 id。
- **target**（必填）：终点节点 id。
- **data**（可选）：边的扩展数据。

```ts
const edges = [
  { source: '0', target: '1', data: { weight: 2 } },
];
```

## 图配置项

`Graph` 的配置对象支持以下字段：

| 选项 | 类型 | 说明 |
|------|------|------|
| **container** | `string \| HTMLElement` | 挂载画布的容器（选择器或 DOM） |
| **data** | `GraphData` | 图数据 `{ nodes, edges, combos? }` |
| **node** | `NodeConfig` | 节点类型与样式 |
| **edge** | `EdgeConfig` | 边类型与样式 |
| **combo** | `ComboConfig` | Combo 样式，详见 [Combo](/docs/guide/combo) |
| **layout** | `LayoutConfig` | 布局类型与参数 |
| **behaviors** | `BehaviorOption[]` | 交互列表 |
| **theme** | `ThemeOption` | 主题：`'light'` / `'dark'` 或带覆盖项的对象 |

## 节点与边样式

### node

- **type**：`'circle'`（默认，圆形）或 `'rect'`（矩形，使用独立的 `width` / `height`）。两者均为真实图元，由不同的 WebGL program 绘制。
- **style**（绝大多数属性都支持值或 `(node) => 值` 的函数形式）：
  - **fill**：填充色。
  - **size**：圆形直径（`circle` 用）。
  - **width** / **height**：矩形尺寸（`rect` 用）。
  - **stroke** / **strokeWidth**：描边颜色与宽度。
  - **opacity**：不透明度。
  - **borderRadius**：矩形圆角。
  - **label** 及一系列 `label*` / **icon** 等标签与图标属性，详见[标签与图标](/docs/guide/label)。
- **stateStyles**：按状态（`selected` / `highlight` / `inactive` 等）覆盖样式，配合 `graph.setItemState()` 使用。

```ts
// 圆形节点
node: {
  type: 'circle',
  style: {
    fill: (d) => (d.data?.cluster === 'a' ? '#5B8FF9' : '#61DDAA'),
    size: 12,
  },
  stateStyles: {
    selected: { stroke: '#1890ff', strokeWidth: 3 },
  },
}

// 矩形节点
node: {
  type: 'rect',
  style: { width: 60, height: 32, fill: '#5B8FF9', borderRadius: 4 },
}
```

### edge

- **type**：`'line'`（默认，直线）、`'arc'`（弧线）、`'cubic'`（三次贝塞尔曲线）、`'polyline'`（折线，支持 `orth` / `tree` / `indented` / `fishbone` 路由）。
- **style**（支持值或 `(source, target, edge) => 值` 的函数形式）：
  - **stroke**：线条颜色。
  - **lineWidth**：线宽。
  - **curvature** / **curveOffset**：`arc` / `cubic` 的弯曲程度。
  - **startArrow** / **endArrow** / **arrowSize**：箭头开关与大小。
  - **lineDash**：虚线。
  - **opacity**：不透明度。
  - **radius** / **router** / **indentTarget** / **trunkGap**：`polyline` 的折角半径与路由参数。
  - **label** 及一系列 `label*` 属性，详见[标签与图标](/docs/guide/label)。
- **stateStyles**：按状态覆盖样式。

```ts
edge: {
  type: 'line',
  style: { stroke: '#e2e2e2', lineWidth: 2, endArrow: true },
}

// 折线（正交路由）
edge: {
  type: 'polyline',
  style: { router: 'orth', radius: 8 },
}
```

样式仅暴露可在 WebGL 下高效实现的属性，便于大规模渲染。

## 布局

通过 `layout` 配置布局，多数算法基于 [@antv/layout](https://github.com/antvis/layout)，选项会透传到底层算法。`type` 之外还支持 `worker: true`，将布局计算放到 Web Worker 中以避免阻塞主线程（≥1000 节点的 force 系布局会自动启用）。

### 支持的布局类型

共内置 **14 种**布局：

| type | 说明 | 常用参数 |
|------|------|----------|
| **force** | 力导向 | `linkDistance`, `nodeStrength` |
| **d3-force** | D3 力导向 | `linkDistance`, `charge` |
| **force-atlas2** | ForceAtlas2 力导向 | `kr`, `kg` |
| **fruchterman** | Fruchterman 力导向 | `gravity`, `speed` |
| **circular** | 环形 | `radius`, `center` |
| **concentric** | 同心圆 | `center`, `minNodeSpacing` |
| **radial** | 辐射 | `center`, `unitRadius` |
| **grid** | 网格 | `rows`, `cols` |
| **dagre** | 有向无环图 / 层级 | `rankdir`, `nodesep`, `ranksep` |
| **mds** | 多维标度 | `linkDistance` |
| **random** | 随机（默认兜底） | `center` |
| **mindmap** | 脑图（自研，树状双向展开） | `direction`, `hGap`, `vGap` |
| **indented** | 缩进树（自研） | `indent`, `rowHeight` |
| **fishbone** | 鱼骨图（自研） | `direction` |

> `mindmap` / `indented` / `fishbone` 为 G6Lite 自研的树形布局，需配合树状结构的数据使用。

### 示例

```ts
// 环形
layout: { type: 'circular', radius: 150 }

// 力导向（大图自动走 Worker）
layout: { type: 'force', linkDistance: 100 }

// 网格
layout: { type: 'grid', rows: 3, cols: 4 }

// Dagre（自上而下）
layout: { type: 'dagre', rankdir: 'TB', nodesep: 40, ranksep: 60 }
```

不传 `layout` 时，将使用节点自带的 `x、y`（缺省为 0）。

## 交互（behaviors）

`behaviors` 为字符串或配置对象数组（`{ type: 'drag-node', ... }`），内置以下行为（均为 **kebab-case** 命名）：

| 行为 | 说明 |
|------|------|
| **zoom-canvas** | 滚轮缩放画布 |
| **drag-canvas** | 拖拽平移画布 |
| **drag-node** | 拖拽移动节点（支持 Combo 整体拖拽） |
| **drag-edge** | 拖拽边的端点 |
| **click-node** | 节点 / 边 / 画布的单击、双击、右键事件 |
| **click-select** | 单击选中节点 / 边，发出 `selectchange` |
| **hover-highlight** | 悬停高亮（节点与边合一） |
| **highlight-node** | 悬停节点时高亮该节点及一度邻居 |
| **highlight-edge** | 悬停边时高亮该边及两端节点 |
| **brush-select** | 框选（矩形） |
| **lasso-select** | 套索选择（自由多边形） |
| **wheel** | 转发滚轮事件（`node:wheel` 等） |

可同时启用多个；当同时启用 `highlight-node` 与 `highlight-edge` 时，边悬停优先。交互产生的事件可通过 `graph.on(eventName, handler)` 监听。

```ts
behaviors: ['zoom-canvas', 'drag-canvas', 'drag-node', 'click-select']

// 监听选中变化
graph.on('node:selectchange', ({ id, selected }) => {
  console.log(id, selected);
});
```

## 主题（theme）

- **字符串**：`'light'` 或 `'dark'`，使用内置主题。
- **对象**：在某一主题基础上覆盖部分 token。

内置 token 包括：`nodeFill`、`nodeSize`、`nodeStroke`、`nodeStrokeWidth`、`edgeStroke`、`edgeLineWidth`、`canvasBackground`、`edgeDefaultColor`、`edgeCategoryPalette`、`edgeArrow`，以及按状态覆盖的 `nodeStateStyles` / `edgeStateStyles`。

```ts
// 使用预设
theme: 'dark'

// 覆盖部分 token
theme: {
  type: 'light',
  edgeLineWidth: 2,
  canvasBackground: '#f5f5f5',
}
```

## API

`Graph` 提供了完整的渲染、数据增删改、状态、查询与视图控制方法。以下按用途列出常用方法（完整签名以类型定义为准）。

### 生命周期

- **constructor(options: GraphOptions)** — 创建图实例，不会立即渲染。
- **render(): Promise\<void\>** — 执行布局、渲染并注册 behaviors，需在创建后调用一次。
- **destroy(): void** — 移除交互监听、ResizeObserver 和画布，销毁实例。

### 数据增删改

- **setData(data)** / **updateData(data)** — 整体替换 / 更新图数据。
- **addNode(node)** / **addNodes(nodes)** / **removeNode(id)** / **removeNodes(ids)**
- **addEdge(edge)** / **addEdges(edges)** / **removeEdge** / **removeEdges**
- **updateNodePosition(id, x, y)** / **updateNodeData(id, data)**

增删改会触发 `afteradditem` / `afterremoveitem` / `afterupdateitem` / `datachange` 等事件。

### 状态与高亮

- **setItemState(id, state, value)** — 设置单个元素状态（如 `'selected'`、`'highlight'`）。
- **batchSetState(items)** — 批量设置状态。
- **clearItemStates(id)** / **getItemStates(id)**
- **setHighlight / clearHighlight**、**hideItem(id)** / **showItem(id)**

### 查询

- **getData()** / **getNodes()** / **getEdges()** / **getNodeData(id)** / **getEdgeData(id)**
- **getNeighborNodes(id)** / **getAdjacentEdges(id)**
- **getNodeCount()** / **getEdgeCount()** / **hasNode(id)** / **getNodePosition(id)**
- **findNodesByState(state)** / **findEdgesByState(state)**
- **pickAt(x, y)** — 屏幕坐标拾取命中元素。

### 视图与坐标

- **fitView(padding?)** — 缩放平移使全图可见。
- **focusItem(id | ids, padding?)** — 聚焦到指定元素。
- **getCamera / setCamera / resetCamera**
- **screenToGraph(p)** / **graphToScreen(p)** — 屏幕 ↔ 图坐标转换。

### 布局

- **setLayout(config)** / **layout()** — 设置并重新执行布局。

### Combo

- **createCombo / removeCombo**、**addToCombo / removeFromCombo**
- **collapseCombo / expandCombo / toggleCombo**
- **getComboData(id)** / **getComboChildren(id)** / **getNodeCombo(nodeId)**

详见 [Combo](/docs/guide/combo)。

### 事件

- **on(event, handler)** / **once(event, handler)** / **off(event, handler)** — 监听 / 取消事件。

常用事件：`afterrender`、`datachange`、`node:click` / `edge:click` / `canvas:click`、`node:hover` / `node:mouseleave`、`node:selectchange` / `edge:selectchange`、`brush:select`、`node:dragstart` / `node:drag` / `node:dragend`、`combo:collapse` / `combo:expand` 等。

```ts
graph.on('afterrender', () => console.log('首帧绘制完成'));
graph.on('node:click', ({ id }) => console.log('clicked', id));
```

### 类型导出

可从 `@antv/g6-lite` 使用：`GraphOptions`、`GraphData`、`GraphNode`、`GraphEdge`、`NodeConfig`、`EdgeConfig`、`LayoutConfig`、`ThemeOption`、`ComboData`、`ComboConfig`、`ElementState` 等。
